# 富贵策略（技术底仓试验）

用户指定保留并在默认 dashboard 展示的技术试验，当前成绩与排名统一见[评分快照](../../../docs/benchmark.md#新增策略与自动评测)。这里只测试高股息国企方案中可复现的技术底仓部分，不把红利成分当作国资属性、4.5% 股息率或连续五年分红的证明。

买入只考虑历史红利池中决策日可交易、上一年末选样市值至少1,000亿元、63日日波动不超过2.5%的成员，并满足以下两类信号之一：

1. 月下吸：36个月收盘最高点回撤至少50%、当前价处于区间最低20%，月DIF/DEA/柱均为负，下轨较上月变化不超过当前价2%。
2. 龙回头：20/30月均线最近六个月突破后的首次月收盘回踩±5%支撑，同时日/周分别满足单侧条件 `P − 下轨 ≤ 0.05 × P`；这不是围绕下轨的绝对距离 ±5%。

候选按63日波动升序、证券代码升序取最多五只。每只首次使用期初总资产18%，合计最多90%；缺额和10%机动预算留现金。窗口内不主动加减仓，持有至90天观察终点。完整方案的股息率分档退出、行业上限及独立机动仓尚未实施，不能用本次分数代表完整策略效果。

[实现](strategy.py)声明 `REQUIRES_POOLS = ("dividend",)`，只需为红利池构建该策略输入；直接传其他股票池时返回现金。`REQUIRES` 为文本 `pool`，以及 `stocks.*` 下的文本 `symbol`、`trade_status`、非空十进制 `market_cap_at_selection`、可为 null 的十进制 `volatility_63`，和可为 null 的布尔值 `fugui.monthly_low`、`fugui.first_pullback`、`fugui.daily_lower`、`fugui.weekly_lower`。仅 `trading` 成员可入选；未知信号不当作成立，波动未知不买，缺少契约时报错。四个技术字段最初见于历史 v8，当前按依赖从原始事实重建，不要求读取 v8 预计算输入。BOLL固定20期/2倍总体标准差，MACD固定12/26/9、至少35根连续月线预热。

参数来自用户描述与2026-11-02首次看成绩前固定的工程定义，没有收益扫描；当前148期已用于多轮其他研究，2006–2017和2018–2025仅分段诊断，不是严格样本外。2026-11-03登记默认看板时没有改动任何参数。历史 v8 预计算切片的首轮记录为总分0.0830748653，平均收益得分0.0155072978，胜率4/148=2.7%，红利池总分0.1808100010；六期触发、九个持仓槽次。这些数字仅为当时的登记证据，不代表原始历史重建后的当前评分快照。完整规则、覆盖与限制见[富贵策略方案](../../../docs/fugui-strategy.md)。
