# 中期动量低波前 3（行业分散）+ 红利止盈与平稳科技股网格

买入规则（3 条）：

1. 只考虑 63 日动量高于 10% 的成员。
2. 在其中分别按 63 日波动升序、中期动量降序排名（中期动量 =（1 + 63 日动量）/（1 + 20 日收益）− 1；指标缺失的排最后），按两个名次之和从小到大依次挑选，同一申万一级行业只取第一只，取满 3 只等权买入；不同行业不足 3 个时少持。行业字段为 null 时不受去重限制；实现不按股票池名称豁免，已知相同行业仍限一只。
3. 没有符合条件的成员时不空仓，改为全池 63 日波动最低的 5 只等权买入。

卖出规则（2 条），未覆盖的持仓持有到期：

1. 红利池的持仓挂 10% 止盈：收盘价较建仓价上涨 10% 以上时，次一个可卖出交易日开盘卖出，所得持有现金到 90 天结束。
2. 科技池中决策日 63 日波动低于 2.8% 的持仓用网格：该股资金分 2 份，建仓买 1 份；网格线为建仓价 × 1.08^i，首次下线为建仓价 ÷ 1.08（约跌 7.41%）、上线为建仓价 × 1.08；收盘触线后调整目标份数，之后按相邻几何网格线继续加减；波动更高的科技股不设卖点。

[实现](strategy.py)的 `REQUIRES` 为文本 `pool`，以及 `stocks.*` 下的文本 `symbol`、`trade_status`、可为 null 的文本 `sw_level1_name` 和可为 null 的十进制 `momentum_63`、`volatility_63`、`return_20`。排除 `no_bar`，合成名次逐项及合计并列按代码升序；低波回退只用已知波动、不做行业去重，回退也无候选则全现金。无额外股票池限制。当前成绩与排名见[统一评分快照](../../../docs/benchmark.md#新增策略与自动评测)，网格执行见[统一口径](../../../docs/benchmark.md#网格)。

历史研究比较：`calm_mid_momentum` 只持 3 只，科技池常常 2–3 只来自同一行业，一起涨也一起跌。每个行业只取一只后，80 个科技池决策点中有 44 期的持仓发生变化，最差一期收益得分从 −14.5 收窄到 −11.1，2006–2017 与 2018–2025 两段总分都比原规则高（3.39 → 3.48，3.15 → 3.26）。

参数来源：除行业上限外全部沿用 `calm_mid_momentum`，没有重新调参。行业上限是在全部 148 个决策点上，以“总分 = 平均收益得分 + 2.5 × 胜率”扫描选定的：上限可选不限、2 只、1 只，同时比较了等权、按波动倒数加权和按名次加权。在相同的其余参数下，1 只始终最好；改为按名次加权或把红利止盈提高到 15%–20%，总分可以再高 0.01–0.07，但这需要在同一份样本上再挑一个参数，因此没有采用。动量门槛偏离 10%（7% 或 12%）时总分明显下降，这一点和原策略相同。行业上限加到回调家族（`trend_calm_pullback*` 持 4–5 只）上时，结果时好时坏，所以它的作用限于高度集中的组合。由于选定时看过两段，检验段不是严格的样本外。
