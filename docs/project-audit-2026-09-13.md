# 项目功能点检与测试报告 · 2026-09-13

## 结论

每日资产自动追踪已实现，覆盖录入、SQLite 持久化、每日沿用、变化比较、加密同步格式和问答授权。此次点检还修复了导航、金额表单与连续编辑方面的问题。最终本地回归没有失败，macOS 和 Android 安装包构建成功。

“完成”指实现与下述验证范围完成，不代表真实云账户、线上模型、行情服务和 Android 真机已经完成联调。相关边界见最后一节。测试使用隔离的临时数据库和合成资产，没有修改用户的实际资产、云数据或钥匙串。

## 每日追踪验收

| 项目 | 实现与验证结果 |
| --- | --- |
| 直接修改金额 | 失焦、回车保存；Tab / Shift+Tab 连续切换金额输入框；显示保存状态；失败保留输入并可重试。组件测试及浏览器操作通过。 |
| 零与空值 | 明确输入 0 可以保存；清空、非法金额不被转成 0。快捷输入、简版新增表单和详细持仓表单均覆盖。 |
| 同日覆盖与重启 | 同日同资产唯一覆盖；连续修改十次仍只有当天最终状态；重复请求幂等、过期版本拒绝；重启后金额和历史一致。 |
| 日期与确认信息 | 固定账户 IANA 时区；补齐过去日期时使用旧余额；只更新被修改资产的确认信息。测试覆盖跨月、跨年、夏令时及另一设备时区不覆盖账户时区。 |
| 自动补齐 | 启动、返回前台、前台跨日和资产保存触发；应用关闭时无需后台任务。前台跨日测试确认同一天不会重复补齐。 |
| 所有资产写入入口 | 新增、完整编辑、快捷金额、删除、行情估值以及负债/基准币种变更均接入事务；强制历史写入失败时资产修改一并回滚。仅修改收入不确认资产。 |
| 多币种与负债 | 缺少汇率可保存原币，但总额显示待补全；保留汇率日期与来源；存在负债时展示净资产；跨基准币种不直接计算差额。 |
| 曲线和比较 | 30 天、90 天、1 年和全部历史；分页查询；每日详情、逐项金额变化、占比变化及区间比较。沿用状态和确认日期保留，新增/移除不被解释成交易。 |
| 数据结构 | 原始日条目按日期和稳定实体 ID 唯一存储；无修改的日状态由可重建缓存展开。负债、基准币种独立记录；查询接口不隐式写库。详见 [设计说明](daily-assets.md)。 |
| 同步与旧数据 | 同步格式 v10 纳入日条目和记账时区，缓存不参与竞争；不同资产修改可合并，同项冲突显式报告；旧 v9 数据恢复和非法导入原子性通过测试。旧组合检查点仍保留原有规则。 |
| 问答接入 | “分析这段变化”预填区间和问题，等待用户发起；日历史受“组合变化”授权控制，负债/净资产另受财务档案授权控制；预览指纹随历史变化失效。测试确认未授权信息不会进入上下文。 |

## 本次 UI 修复与调整

- 修复地址 hash 改变后正文未切换的问题，同时处理浏览器前进/后退。
- 已录入资产的用户进入“我的情况”时优先看到对应资产分组，减少更新金额前的操作。
- 添加“更多资料与记录”和辅助页面返回路径，保留两个主要导航入口。
- 金额输入保留原始文本，区分空值和 0；简版和详细表单允许缺少汇率的外币资产录入。
- Tab 直接进入下一项金额，支持连续更新；保留失败草稿和版本冲突提示。
- 历史顶部展示总额、变化、负债对应净资产；曲线区分沿用值，详情展示逐项差额与占比变化。
- 调整卡片、日期选择和移动端布局。浏览器在 1280×720 与 390×844 下检查，所检查页面没有出现横向溢出。
