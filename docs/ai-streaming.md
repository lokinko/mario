# 问答流式回复

问答页面通过带认证和 `If-Match` 的 `POST /api/analysis/stream` 接收 SSE。请求需携带 `/api/analysis/preview` 返回的 `previewRevision`。非流式调用使用 JSON 接口 `/api/analysis`。

事件的 `data` 是 JSON，`type` 分为：

- `status`：`message` 表示当前研究或核对阶段。
- `draft`：`answer` 是当前草稿全文，每次替换上一份草稿。结构化 JSON 中的正文在生成过程中转为可读文字，引用路径等内部字段不会混入正文。修复结构化输出时草稿会重新生成。
- `complete`：`result` 是通过结构、来源和建议校验，并已保存到历史记录的 `AnalysisResult`。页面用它替换草稿，供后续追问使用。
- `error`：`message` 是失败说明。草稿不是已完成报告，不写入历史记录，也不作为后续追问的已完成上下文。

单次问答流式生成报告，格式校验失败时清空草稿并修复一次。本地资料检索与摘录在发送前确定性冻结；可选原生搜索在执行期间发送状态，并把实际取得的来源追加到本次引用目录。支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，以及经配对桥接调用用户电脑上的 Codex App Server 或官方 ChatGPT Responses。Codex 凭证由 Codex 管理，本机 ChatGPT 凭证由 Mario 本机授权模块管理，均不上传服务器。

独立 AI Agent 提供 `/execute/stream`，后端转发 `status` 和 `draft`，收到完整结果后由后端保存，再向页面发出 `complete`。前后端和 Agent 都要求明确的结束事件，连接关闭不能当作成功。浏览器和后端不会重发整次问答，已接受响应后的流中断或错误也不会自动重发。

普通 API Provider 在接受响应前明确收到可重试的 HTTP 429 或 503 时，最多重试两次。优先尊重 `Retry-After`（秒数或 HTTP 日期），缺少有效提示时按 2 秒、4 秒退避并加入随机延迟。单次等待最多 30 秒、重试时段最多 45 秒；供应商要求更久时返回提示，不能缩短等待提前重试。此路径每次模型调用的 120 秒总期限包含等待和读取正文。等待通过 `status` 显示，可随时“停止生成”；真实请求次数计入报告轨迹。

本机桥接的单次模型调用上限为 180 秒：Codex 仅在尚无助手内容且错误可重试时最多重试两次；官方 ChatGPT 不自动重试推理请求。完整问答执行上限 25 分钟，Agent HTTP 上限 26 分钟，网页总期限 30 分钟、流空闲期限 60 秒；心跳不会延长总期限。具体重试分类见[本机桥接](codex-bridge.md#超时失败与重试)。

已识别的余额耗尽、额度或消费上限错误不重试；提示用户检查模型服务商的 API 余额和项目/组织限额。错误提示注明失败阶段。仅解析有界的错误类型和代码，不向页面或日志暴露供应商错误原文、密钥或用户输入。第三方服务未提供可识别错误代码时，提示限流或额度限制两种可能，不能凭 429 确定余额不足。

SSE 定期发送心跳，响应包含 `X-Accel-Buffering: no`，避免 Nginx 默认缓存。部署时必须同时更新后端、Agent 和 Web 静态资源；自定义代理也应允许 SSE 即时转发。

发送后，按钮变为“停止生成”，准备资料和流式生成期间均可点击。停止会取消流式请求、立即恢复输入，保留已收到的草稿和原问题，显示“已停止生成”；停止后的迟到事件或结果不会更新页面，也不会干扰下一次发送。准备阶段停止后不再发起模型请求，中止的草稿不作为后续追问的完整回答。

页面关闭或组件卸载会取消正在读取的回复；应用内导航到其他页面时，问答组件保持挂载，回复和草稿继续保留。服务端执行由响应正文持有，连接取消时释放执行任务和并发名额。失败或超时保留草稿和问题，可先查历史记录再重试。账号切换会重建账号页面，旧账号的后续事件和结果不会发布到当前页面。模型阶段或本地数据校验之前仍可能需要等待。

问答界面将阶段状态映射为“准备资料 → 检索 → 分析 → 校验 → 完成”的步骤条，无法识别的阶段保留服务端原文；草稿标注“未校验”。界面不根据展示进度判断服务端完成，仍只接受 `complete` 作为成功。

开始前可打开“查看将发送的数据”，读取当前预设的实际资料分组与 payload；预览不调用模型。发送前仍重新读取预设、核对并冻结上下文。报告展示回答、建议和可选追问，引用编号在抽屉打开原始资料，末尾可展开依据与局限；原文与外链按来源契约校验。进度步骤是状态展示，不表示 v7 的研究计划、候选比较和风险审查模型阶段仍在执行。
