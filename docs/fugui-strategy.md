# 富贵策略：研究实现与买点观察的边界

用户认同的出发点是：寻找股息足够高、基本面和长期需求相对稳定的公司，在合意的趋势位置研究买入，愿意长期持有收息。当前实际使用优先服务于认可公司的[买点观察助手](buy-watch.md)，不以完成整套策略回测为前提。

本页只描述仓库保留的研究实现及局限，不作为完整资金管理策略的开发清单。现有研究代码、原始数据和历史成绩保持可追溯；早期实验范围与验收证据见[历史审计](audits/benchmark-fugui-v1-20261103.md)。

## 两套规则不可混用

| 维度 | 当前买点观察 | benchmark 富贵技术底仓试验 |
| --- | --- | --- |
| 对象 | 用户认可的沪深 A 股，含已持有与未持有公司 | 固定历史红利池；科技池返回现金 |
| 股息率 | 按账号配置的已实施现金分红 TTM 税前股息率门槛，默认 ≥5% | 未实现历史股息率准入，红利池身份不证明达标 |
| 买点 | 按账号配置的日周 BOLL(20,2) 条件同时判断；默认日下轨价格 ±2%、周收盘价 ≤ 周中轨 | 月下吸或龙回头，按下述历史研究定义 |
| 个人背景 | 结合授权持仓、现金与真实交易讨论 | 不读取账号或个人交易 |
| 仓位与退出 | 不自动给买入数量或卖出规则 | 每只预算18%，最多五只，缺额留现金，持有至90天观察终点 |
| 用途 | 提示值得研究的变化 | 比较固定研究协议下的技术规则表现 |

BOLL 使用20期收盘均值与两倍总体标准差。观察助手的距离始终相对账号所选参考轨价格；默认日线按下轨价格衡量，跌破超过 2% 不通过，默认周线要求收盘价≤中轨、含相等。用户可调整参考轨、比较方式和偏移，完整定义只在[观察规则](buy-watch.md#明确规则)维护。研究成绩既不代表这套默认规则，也不代表任何账号自定义规则的成绩。

## 现有研究实现

唯一策略实现为 [`benchmark/strategies/fugui/strategy.py`](../benchmark/strategies/fugui/strategy.py)，参数来源和样本说明在[策略说明](../benchmark/strategies/fugui/strategy.md)。技术输入由共享指标计算及 [`scripts/benchmark_fugui_study.py`](../scripts/benchmark_fugui_study.py) 的显式研究入口构建，执行与评分归隔离运行器和评分器。

当前研究只在历史红利池中选择上一年末选样市值至少1,000亿元、63日波动不高于2.5%的证券，再检查两类技术信号的并集：

- **月下吸**：36根月收盘中，当前价不高于最高值50%，且位于区间最低20%；月 DIF、DEA 和 MACD 柱均为负；月 BOLL 下轨较上月变化不超过当前价2%。
- **龙回头**：最近六个月突破20月或30月均线后的首次月收盘回踩至对应均线±5%，中间月收盘均高于均线105%；日、周分别满足 `P−LB ≤ 0.05×P`。这一单侧研究条件不对应观察助手的默认或账号自定义日周条件。

MACD 使用 EMA(12/26/9)，至少35根连续月线预热；周/月均采用截至决策日的已知收盘，包含未结束周期。未知缺行使对应周期无效；已确认停牌才沿用此前已知收盘估值。不能用未来价格恢复历史信号。

候选按波动升序、代码升序取最多五只，每只18%，未使用预算留现金。历史国资属性、连续分红、行业分散、机动仓、动态股息率退出与多年连续持有均**没有在这项技术试验中验证**；此处列的是结论局限，不是当前开发计划。

## 成绩与复现

首轮预计算 v8 与后续从原始历史重建的成绩属于不同输入记录，不能混为同次实验。当前成绩、名次和分段只在[benchmark 成绩表](benchmark.md#新增策略与自动评测)维护；首轮来源哈希、成绩、发布和验收保留在[历史审计](audits/benchmark-fugui-v1-20261103.md)。

固定季度90天窗口、预热缺失及未实现的基本面条件限制了结论；既有148期已多轮研究，分段只能作诊断，不是严格样本外检验。研究成绩不能证明或否定用户当前观察规则的有效性。已有[富贵研究回归](../benchmark/tests/test_fugui_study.py)覆盖技术口径、未来数据隔离、预热缺口、双周期条件及预算边界；这些覆盖不等于检验了未实现的基本面准入或长期执行方案。

当前持续评测从固定原始事实重建输入，部署只同步成功快照；不再在部署时本机评分。维护和复现入口见[benchmark](benchmark.md)、[原始数据与指标](benchmark-data.md)。显式复现旧 v8 归档可运行：

```bash
npm run benchmark -- hub-fetch --repo lokinko/mario_bench --labels-repo lokinko/mario_bench_labels --tag pool-scoring-v8 --out .runtime/benchmark/pool-scoring-v8
npm run benchmark -- bench-run --release .runtime/benchmark/pool-scoring-v8
```

这条命令复现旧切片，不替换当前原始重建看板。现有输入和标签仓库按用户要求公开，分仓不构成访问隔离；标签仍不得进入历史决策。研究与线上账号、事务和观察名单保持独立，发布与推送不等于部署。
