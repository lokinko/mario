# 富贵策略

本方案把用户给出的“高股息国企、月线低吸、底仓加滚动”描述转成可检验规则。它是对该描述的工程化定义，不代表吴富贵本人认可的完整规则，也不补写未经核对的个人观点。当前买点按2026-11-03用户修正，其他阈值沿用首版，没有根据本次收益调参。

**当前交付是完整规则方案与更新买点后的技术底仓测试。历史股息率、国企属性、连续分红及红利池行业尚缺可核验输入，完整策略回测尚未完成。** 技术测试不把这些缺项当作通过，不据此判断原策略是否有效。

## 1. 完整方案的准入与资金安排

目标是用闲置资金持有低位、低波动的大型高股息企业，通过分红与估值修复获益；机动资金只服务于已有持仓，不融资、不做空。

| 项目 | 确定性规则 | 时点要求 |
| --- | --- | --- |
| 企业属性 | 实际控制人为中央或地方国资 | 使用决策前已披露且当时生效的控制人记录，不能用今天的标签回填 |
| 公司规模 | 总市值至少 1,000 亿元人民币 | 完整版按决策日价格和当时已知总股本计算；当前技术测试只能用上一年末选样市值 |
| 分红连续性 | 最近五个完整年度均有普通现金分红 | 已实际实施且决策时已知；缺记录不等于零分红，也不等于满足 |
| 股息率 | 新买入时普通现金分红 TTM 股息率至少 4.5% | 近 365 天实际实施的每股现金分红 / 决策日未复权收盘；送转后统一股份单位，排除特别分红；不使用未来派息或预测分红 |
| 波动上限 | 最近 63 个有成交日的日收益总体标准差不超过 2.5% | 沿用 benchmark 原字段，不年化；缺失不参与 |
| 分散 | 五个固定资金槽，每槽最多总资产 20%；同一一级行业最多两个槽 | 同行业上限 40%，不足五只不凑数、不集中分配空缺资金 |
| 底仓/机动仓 | 每槽 18% 底仓、2% 机动预算 | 合计上限 90%/10%；资金按各槽隔离，不互相透支；机动资金未触发时持现金 |

4%–6% 是原描述的常见股息率范围，本方案以其中明确的 4.5% 作为新买门槛，不另加 6% 硬上限。“五年分红”“2.5% 日波动”“五槽”“行业最多两槽”是为消除模糊性作出的研究定义，并非用户原文已经指定的精确参数。

## 2. 买点定义

以北京时间交易日收盘后生成信号，下一可执行交易日开盘成交。技术价格统一使用同源后复权收盘，股息率另用未复权价格；不能把复权价当真实成交价或股息率分母。

BOLL 为 20 期收盘均值 ±2 倍总体标准差，各自在日、周、月频率计算；MACD 用 EMA(12)−EMA(26)，DEA 为 DIF 的 EMA(9)，柱为 2×(DIF−DEA)。定义依据 [BOLL 原作者的指标说明](https://www.bollingerbands.com/_files/ugd/58be43_d09c50b6e8ea4afd9af0523ef94de876.pdf)和 [Fidelity 的 MACD 说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)。本次月 MACD 以连续历史首个收盘初始化 EMA，DEA 初值 0，至少 35 根月线；种子与可用历史长度会影响边界信号，应在补齐长历史后再次核对。

两个买点共用三个前提：**日 BOLL 下轨、周 BOLL 下轨、月 MACD 柱小于 0**。月下吸再要求月 BOLL 下轨；龙回头再要求月 BOLL 回踩中轨。月 MACD 不要求 DIF、DEA 小于 0，不要求刚刚由正转负；柱已经处于负值区即可。

| 买点 | 同时满足的技术条件 |
| --- | --- |
| 月下吸 | 日下轨 + 周下轨 + 月下轨 + 月 MACD 柱 < 0 |
| 龙回头 | 日下轨 + 周下轨 + 月回踩中轨 + 月 MACD 柱 < 0 |

沿用用户确认的收盘价与5%容差：下轨判断为`P−LB ≤ 0.05×P`，因此低于下轨也通过；中轨回踩为上月收盘高于上月中轨，当前收盘落在当前月中轨的`[95%,105%]`。不使用盘中最低价，也不保留首次回踩、六个月突破、30月均线、三年腰斩或下轨走平条件。月内决策使用截至当日的当前月收盘，周线同理。

两类买点取并集，不重复占用资金槽，仍执行上节准入与低波条件。候选多于五只时按63日波动升序、证券代码升序选择；完整版还需执行行业上限。新买点来自用户明确修正，5%为用户确认沿用的参数，没有根据本次收益调参。

## 3. 卖出与滚动规则

完整方案按收盘后的当时已知股息与价格判断，次一可卖出交易日开盘执行；停牌或一字跌停时顺延。

- **底仓分批退出**：TTM 股息率首次低于 3.5% 时卖出该槽当时底仓的一半，剩余底仓低于 3.0% 时全部退出。以槽内状态记录第一档已执行，不能每一天重复减半。股息率重新达到买入门槛且出现新买点后才重新建立槽位。
- **基本面失效**：控制人不再满足国资条件，或最新已核验分红记录打断连续性时，停止新买并退出该槽；披露延迟或未知字段只记为待核验，不凭“未知”伪造分红中断。
- **机动仓**：仅对已有底仓、且月收盘高于 20 月均线的股票启用。周收盘处在周 BOLL 下轨至中轨之间时，用该槽不超过 2% 的机动预算买入；周收盘触及上轨时卖出机动仓，资金留在该槽。底仓退出时同时关闭机动仓。滚动买卖不侵占其余 18% 底仓。
- **日内 T**：不纳入首版。没有分钟行情、可卖旧股数量与逐笔执行模型，日线回测不能声称验证了日内 T。

股息率下降可能同时来自股价上涨和派息变化，不能简单把 4.5%→3.5% 换成固定涨幅止盈。动态 BOLL 也不能用建仓时上轨或现有固定百分比网格冒充。本次测试因此不添加这种替代卖点。

每次操作的比重必须进入当期策略：技术底仓测试每只首买占期初总资产 18%，无主动卖出，缺额和机动预算留现金；完整方案每槽底仓 18%、机动预算 2%，第一档退出卖当时底仓数量的 50%，第二档卖剩余底仓的 100%，机动仓买卖只在该槽 2% 预算内。benchmark 现已支持 `sell_fraction` 的一次部分卖出及逐笔操作展示，详见[操作比重与逐笔记录](benchmark.md#操作比重与逐笔记录)；它仍不能单独实现本方案的双档状态、历史股息率触发和独立机动仓，本次只更新技术买点，未实现这些完整执行条件。

## 4. 当前 benchmark 实际测试了什么

沿用[架构说明的离线研究边界](architecture.md#离线-benchmark-研究工具)。数据流为既有 Baostock 后复权/交易日历缓存 → 决策前技术特征 → 不可变v9评分切片 → 隔离策略子进程 → 原有评分器。状态与文件均在 `.runtime/benchmark/`，不涉及账号数据库、业务事务或在线交易；评分结果沿既有持续评测快照同步至看板。

[`scripts/benchmark_fugui_study.py`](../scripts/benchmark_fugui_study.py)拥有缓存对账与技术特征构建；策略唯一实现是[`strategies/fugui/strategy.py`](../benchmark/strategies/fugui/strategy.py)，成交、成本及评分继续归`scoring.py`。v9保留v8全部其他字段、`long_history`及结果标签，替换`fugui`为五个BOLL/MACD信号；旧技术买点和重复实现已删除。失败保留源缓存，输出用不可覆盖的新目录重建。没有账号数据或在线事务迁移。

| 完整规则 | 当前测试状态 |
| --- | --- |
| 高股息、央国企、连续五年分红 | **未实现**：仅以当年历史红利池作为研究范围；成分身份不能证明这三个条件 |
| 千亿规模 | 使用已有 `market_cap_at_selection`，是上一年末选样市值，不是决策日市值 |
| 低波动、月下吸、龙回头 | 按上述确定性技术定义实现 |
| 行业分散 | **未实现**：红利池没有历史行业字段；不能据证券代码或今天的行业推断历史分类 |
| 90% 底仓 | 每只固定 18%，最多五只，未获信号的槽位留现金 |
| 10% 机动与收益率卖出 | **未实现**：机动资金留现金；已买底仓持有至 90 天观察终点 |
| 多年持有、等待半年至一年 | **未验证**：benchmark 各季度独立建仓，观察 90 个自然日，不能延续底仓与税务成本 |

科技池所有决策点返回现金，保留在统一排名中，不删除不适用样本提高总分。红利池单独成绩更贴近本策略适用范围，但仍只是技术底仓测试。

日线缺行留未知，切断对应周/月历史；明确停牌使用此前已知收盘估值，不使用停牌行中的异常价。日线计算只使用截至决策日的记录；周线用 ISO 周截至决策日最后一个已知收盘，决策在周中时包含当周未结束部分；月线同样是截至决策日的月收盘。每个周期只要出现未知缺行就保持无效，不用该周期后来恢复的收盘掩盖缺口。月 MACD 从最近缺失周期后的连续月线重新预热，缺必要信号的股票留现金。

## 7. 完整策略验收还缺什么

1. 为历史候选补齐至少五年、同源且连续的预热行情，检查 EMA 种子与复权口径的敏感性；保留上市史不足和真实缺行，不能缩短窗口。
2. 建立按真实披露/生效时间版本化的国资控制人、普通现金分红、股份单位与行业台账，并逐条保留原件来源。未核验的供应商当前值不能回填历史。
3. 在独立执行模型中分别维护底仓和机动仓、分批退出状态、现金分红与红利税，验证动态周 BOLL、次日成交、T+1、停牌及一字涨跌停；未经这些检查不能把现有网格接口称为 90/10 滚动。
4. 增加多年连续持仓与年度分红考核，并同时报告回撤、资金占用和换手。先锁定完整规则，再选此前未用于选参的检验区间；现有 90 天得分保留为统一对照。

这四项是完整回测的明确未完成条件，不是本次已验证能力。
