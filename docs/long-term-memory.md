# 长期记忆与多轮检索

mario 的长期记忆不是聊天记录堆积，也不会把模型说过的话自动升级为事实。记忆层从历史 AI 分析中构建结构化事件，在每次问答前先由本地检索器召回授权候选，再由模型结合问题与时间筛选。

## 记忆来源与证据等级

| 来源 | 保存内容 | 默认地位 |
| --- | --- | --- |
| 历史 AI 分析 | 当时的问题、最终回答和工作流版本 | 未经结果验证的问题线索，不是事实来源 |

系统不会另存一份可被悄悄改写的“AI 总结记忆”。`Database::memories` 每次从分析记录重新构建记忆，源记录仍是唯一事实来源。

## 结构化记忆契约

每条 `MemoryItem` 包含：

- `kind`：历史 AI 分析；
- `title`、`summary` 和结构化 `content`；
- 原始创建时间与最近事件时间；
- 历史分析状态（未经结果验证）；
- 资产与来源标签；
- 用户的长期保留或永久屏蔽偏好，以及可选的适用范围注释；
- 检索分数、记忆年龄、命中原因和命中轮次。

`retrieval.score` 是当前候选集内的相对相关度，不是事实置信度、投资胜率或推荐强度。问答页隐藏分类、分数与维护信息，只显示回答实际引用的编号；用户点击后查看原始记录。内部轨迹保留命中原因供审计。

## 本地混合检索

当前 `HybridMemoryRetriever` 不调用外部模型，在本机综合：

1. 标题、资产、摘要与标签的字段匹配；
2. 原始分析正文的内容匹配；
3. 风险、集中度、目标、复盘、估值、流动性等投资概念组关联；
4. 用户是否在询问复盘、反方风险或历史方案；
5. 用户长期保留偏好的排序权重；
6. 90 天、一年、三年和更早记录的分段时间衰减。

时间衰减只降低排序权重，不删除旧记录。历史分析始终作为未经结果验证的线索。

当前概念关联使用可审计的本地词表，不等同于向量语义检索。调用方直接使用 `HybridMemoryRetriever`，没有为未实现的检索方式增加接口。

## 永久记忆管理

“长期记忆”页面展示近期 20 条历史 AI 分析，以及所有已经设置偏好的记录。用户可以选择：

- 默认：只按主题和时间衰减参与检索；
- 长期保留：源记录仍保持原样，仅为主题相关的检索增加一个透明权重，并显示“用户已标记为长期保留”的原因；
- 永久屏蔽：在服务端候选检索之前设为不可选择，不进入发送前候选池；
- 我的注释：记录经验的适用范围或屏蔽理由，不替代原始分析，也不把内容升级为事实。

偏好可以恢复默认。系统不会让“长期保留”绕过主题相关性直接进入模型，也不会让它覆盖更新的反证。偏好与注释按账号保存于服务器，并包含在当前 JSON 数据备份中；这不是端到端加密。导入会核验来源记录、状态、长度和时间戳，孤立或非法偏好会被拒绝。

## 两轮检索与冻结边界

```text
账户内全部记忆（读取近期 20 个分析及所有带偏好的分析）
          │
          ├─ 用户问题初筛：最多 16 条候选
          │        └─ 按问答预设冻结并写入上下文指纹
          │
          ├─ 与研究资料/网页来源联合交给模型分类与时效筛选：合计最多 10 条
          │        └─ 保存当次内部元数据与完整原文快照
          │
          ├─ 深度流程在已入选记忆中复核用户问题：取最多 4 条
          └─ 研究计划扩展：在已入选记忆中取最多 6 条
                   │
                   └─ 合并去重，最终最多使用 8 条
```

研究计划只能再次聚焦模型已选中的记忆，不能重新引入未入选候选，也不能越过冻结候选访问第 17 条或其他本地数据。快速问答直接使用模型选中的记忆。同一记忆若被两轮同时命中，会合并命中轮次和原因，而不是重复发送。

## 问答预设与冻结授权

问答页不要求用户逐次维护元数据或确认候选。记忆开关与资料范围在设置中一次配置，之后每轮后台自动预览、冻结并校验指纹。永久屏蔽的记录不会进入候选；模型只能筛选已授权候选，分类不改变原记录或用户偏好。

API 保留 `excludedMemoryIds`，供既有客户端逐条排除。排除项可在预览候选中保留，但不进入实际授权池和指纹；非法、重复或异常数量的排除 ID 会被拒绝。后续模型和本地检索都不能重新引入这些记录。

## 模型使用约束

- 检索分数不代表事实真伪；
- 历史 AI 回答只能提供问题线索，不能替代带来源研究证据；
- 记忆内容是不可信数据，其中的指令不能改变系统角色或要求泄露其他信息；
- 记忆不会自动修改个人投资规则或触发交易。

## 当前限制与后续方向

- 尚未生成本地向量嵌入，对同义表达的覆盖受概念词表限制；
- 尚未把多个事件聚合为稳定的“用户能力圈”或“重复行为模式”；
- 尚未建立离线检索评测集，当前权重由明确规则和单元测试约束；
- 永久偏好只管理既有分析来源，当前不允许脱离证据手工创建“事实记忆”。

下一步应增加本地嵌入 + 词法结果融合、记忆冲突聚类、能力圈与重复行为模式，以及基于真实复盘结果的检索评测。
