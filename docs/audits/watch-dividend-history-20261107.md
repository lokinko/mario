# 2026-11-07 买点分红三年明细与资料复核

## 目标与设计

解决详情仅展示一年事件、无法检查近三年实际分红连续性的问题。沿用[架构说明](../architecture.md)第 3 节依赖方向、第 6.5 节观察数据流、第 7 节状态归属：公开来源仍获取完整报告期，`models/watch::evaluate` 新增独立的 `dividendHistory` 展示证据，按实际行情日向前 36 个日历月（含两端）筛选已实施事件。原 `dividendEvents` 继续保存 TTM 计算窗口，股息率、送转归一、5% 规则及 AI 冻结计算依据不变。前端 `WatchDividends` 显示全部三年事件、税前当次每十股金额、送转、来源与 TTM 窗口标记。

新增字段为可选，不新增表、接口或备份版本；旧观察不推断三年历史，显示已有 TTM 事件，下次成功检查补齐。历史观察和已完成分析不重写。失败保留原资料与覆盖日，来源未知不视为零分红。代码回退可忽略新增 JSON 字段，公开库仍沿用同一资料契约和事务。
