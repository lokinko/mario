# 2026-11-07 模块 spec 与实现对齐记录

## 核查基线与范围

开始时主工作区干净，`main` 与 `origin/main` 均为 `f52f82e`。本轮使用观察产品、财务同步、AI 授权与桥接、研究运维四个角色分文件审查，由主负责人维护全局索引、交叉复核及交付；另补查当前策略目录内的说明与实现。

[当前 spec 索引](../README.md)按 20 个业务与运行模块连接规范、代码和既有测试，覆盖 29 份原有顶层领域／架构文档。仓库沿用这些文档作为 spec，不新建竞争的需求目录。22 个策略说明（18 个策略与 4 个对照）与对应实现另行核对；问答质量基线夹具说明作为验证资料读取，不触发真实模型评测。

本记录是本轮核查快照，不是新增需求或此刻线上部署证明。审查没有删除用户数据、历史审计、策略实现或已有采集／评测任务，也没有重新研究参数或计算成绩。

## 确认并纠正的主要不一致

| 模块 | 旧说明或冲突 | 当前事实与处理 |
| --- | --- | --- |
| 产品入口与观察规则 | 首页仍要求日周都在下轨附近；方法论与研究边界把默认值写成唯一规则 | 区分按账号保存的当前规则与默认值；默认周线为中轨及以下，具体规范集中于[观察 spec](../buy-watch.md) |
| 分红与网格 | 当前行为中重复两批一次性筛选的价格表；网格仍用固定观察阈值解释 | 历史数字保留在原始资料与审计，当前文档只保留批次范围、来源及迁移用途；测算与真实成交分开，核对实际预算、股数与档位校验 |
| 复盘与方法论 | 规则描述为折叠区；问答按钮声称自动带入复盘正文 | 实际是分类标签；按钮只发送通用问题，具体正文需用户手工提供；方法论范本只填草稿，保存值才冻结入分析 |
| 行情与每日资产 | 声称读取快照、版本、每日补齐或定时任务会自动写账号报价与完整汇率 | 公开缓存预热与账号显式写入分开；GET／ensure 不查价或自动刷新账号，持仓保存仅在用例需要时补价；未新增自动更新能力 |
| 资产可用性与规划 | 已确认公司行动后的参考价仍被描述为阻断计算；期权被说成剔除再平衡目标 | 按结构化问题和 `amounts.usable` 确定影响，参考价本身不阻断；期权及其标的排除普通动作，目标权重仍参与校验 |
| 同步与财务回执 | 局部汇率 GET 和显式保存未区分；回执描述为返回原始响应 | 仅局部 GET 不采纳快照版本，显式写入按现政策推进；回执确认已提交操作并返回当前快照，包含期权报价重放 |
| 备份与迁移 | 混淆账号 JSON、租户 schema、整站加密包版本；遗漏公共资料或误称模型预设随 JSON 恢复 | 明确各自版本与范围、settings 导出白名单、整站包包含 `mario_market` 与受加密保护的主密钥；保留有用途的旧数据恢复，详见[同步](../cloud-sync.md)和[迁移](../data-migration.md) |
| AI 生命周期 | 结构图称分析完成后重新校验输入版本；文档仍暗示旧多阶段报告与完整审计界面 | 执行前校验预览指纹，运行期间使用冻结值，复锁后保存；旧报告只读；界面可见内容与详情 API 审计分开 |
| AI 授权与模型执行 | 网站身份、本机 OAuth、Codex 配对用途混用；超时与验证方式描述混用 | 三条边界分开，普通与本机调用期限分别说明；默认模拟桥接、独立协议夹具、真实 OAuth／付费模型验收分别列出 |
| 原值引用校验 | spec 要求非空标量，但 `validate_source_types` 仍接受空字符串 | 保留既有要求并修实现：拒绝空白字符串及非标量，允许有效数值与布尔值；增加拒绝空白和保留 `0`／`false` 的行为回归 |
| 历史实验与成绩 | 逐批最小输入版本、历史排名、资料缺口散落为当前约束或待办 | 历史记录明确日期、切片与样本限制；当前按字段依赖；全局架构与模块边界只保留稳定职责和接口，引用领域规范及历史审计 |
| 协作与模块归属 | 缺少统一 spec 入口；快速编辑排队归到回执辅助文件；研究步骤混入通用开发流程 | 新建统一索引和协作约定；排队归组合 API，回执归单请求辅助模块；开发流程与研究扩展分开，分红行为归回观察模块 |

各模块 spec 增补了对应源码与现有验证依据。索引中的测试链接表示可追溯的现有覆盖，不表示本轮重跑全部验证。

## 清理与保留的界限

- 从当前规范移除取消或不存在的 CSV 持仓预览、旧目标／检查点流程、服务器侧评分、旧生成阶段及不实界面承诺；仍有代码的财务、规则、复盘和研究能力继续如实说明。

- 账号旧备份、历史报告和已退役记忆元数据的最小恢复适配保留用途与移除条件；文档清理不等于删除数据或恢复退役入口。
