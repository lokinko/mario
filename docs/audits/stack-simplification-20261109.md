# 小规模自建技术栈简化验收（2026-11-09）

## 交付范围

以买点观察、真实账本和讨论的可靠性为目标，完成四项优先改造：

- 恢复 `d663f51` 删除但仍被调用的 14 个验收脚本，并合并此前删除的架构回归。按当前模块边界修正旧断言；新增 `check:entrypoints`，在构建与数据库验收前检查 npm 和完整门禁的脚本目标。
- 汇率查询、汇率刷新、普通持仓保存和估值核验在外部等待期间释放账号锁。写入重取锁后校验冻结版本；只读汇率只核对所用汇率表，允许无关修改。取消不提交后续写入。回归使用同账号的独立 PostgreSQL 连接实测 advisory lock。
- 将传输版本、同步屏障、写入计数、待更新状态、取消和快速编辑排队顺序收敛到账号会话。切换后旧响应、等待中的写入和队列均失效，覆盖 A → B → A；页面继续持有草稿，应用层继续持有快照。
- 新增 `check:contracts`：用真实 Rust 序列化结果检查 TypeScript 精确金额和观察规则，并比较当前 HTTP 路径的方法／版本政策。修正公共目录仅 PUT 免账号版本的前后端差异。

同时修复门禁运行暴露的问题：Git 源码指纹分别枚举已跟踪与未跟踪文件，避免 Windows 目录占位输出导致 EISDIR 或遗漏后代文件；桥接过期验收改用 Tokio 虚拟时间推进，避免向单调时钟原点之前回退；前端 jsdom 并行数限制为 4，保留原断言和超时；备份流测试将捕获上限提高至 64 MiB，当前隔离夹具归档为 1,480,813 字节，超过 Node 默认的 1 MiB。
