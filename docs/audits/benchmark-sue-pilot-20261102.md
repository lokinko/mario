# SUE 财务输入试点（2026-11-02）

本批完成中南传媒（601098.SH）2012Q1–2015Q3 共15份原始定期报告的归档、结构预检和财务表格摘录，验证了单季EPS构造与按时点计算。**这是输入试点，没有新增策略成绩，没有改变v6、正式策略目录或Top-10，也没有发布新的HF数据。** 601098在本切片入池至2015年，选择该历史区间是为了验证实际会用到的输入，而不是用当前财报替代历史披露。

## 来源、口径与设计

规则依据为[Novy-Marx作者稿](https://mysimon.rochester.edu/novy-marx/research/FMFM.pdf) §2.1：最近季度EPS同比差，除以过去两年八次公告盈利创新的标准差，至少六次观察；原文使用Compustat EPSPXQ与RDQ。本地先固定八个日历季度，含当前季，采用样本标准差（ddof=1）。是否含当前项及ddof属于本地明确的实现选择，不声称原文给出了全部计算细节。

本试点使用中国会计准则下**报告普通股利润（含当地非经常性损益）**，不同于原文美国剔除非常项的EPSPXQ。既不把本地扣非口径等同于美国非常项，也不把供应商名为`epsTTM`的字段当作单季EPS。Baostock财务接口探测在登录阶段发生网络接收错误，未得到任何财务响应，因此没有据此确认该字段的实际数值或公式。

依赖沿用[架构第10节](../architecture.md#10-容量边界与已知架构债)的离线研究路径。新增`scripts/benchmark_sue_study.py`只依赖标准库与`benchmark.files`：人工核验台账→原件哈希和来源时间校验→累计普通股利润差分→单季EPS→SUE。台账和原件在`.runtime/benchmark/sue-pilot-20261102/`；不读未来收益标签，不访问账号数据库，不构造正式发布包。没有新的在线状态、事务或迁移。

15份PDF均通过`pdf_read_preflight/1`的PASS检查，文件页数、枚举页数和读取页数一致。逐期核对原始当前列、币种、元/股单位和累计期间；关键季度/累计表、普通股分母和股份未变说明另经Poppler渲染核对。结构预检只证明文件可读，不证明全部财务语义已自动核验。

## 构造规则及发现

1. Q1以当期累计普通股利润为单季利润；Q2/Q3/Q4用同年相邻累计利润相减。仅在已核验同一盈利口径、单位和**全累计期间普通股股数恒定**时除以该股数；缺相邻累计、分母证据或存在冲突则保留null。
2. 禁止直接差分已舍入的累计EPS。例如2014H1累计0.36、一季度0.13相减为0.23；原始利润差400,649,681.86除以1,796,000,000约为0.223078887，舍入为0.22。2013Q3摘要0.40是1–9月值，合并利润表7–9月EPS为0.13，不能把0.40当作第三季度EPS。
3. 公告日期按23:59:59后可得，决策为季度末18:00。同一期间选择决策时已知的最新台账版本；单季值的可得时间是当前累计、上期累计和股数证明时间的最大值。后来的年报证明不能用于更早的决策。
4. 形成窗固定为最新已知报告期及前七个日历季；每项同比需该季和四季前EPS。至少六项，最新一项也必须有效；缺失不会把窗口向过去延长，最新报告无法算时不会退回旧报告。跨同比或跨窗口股数变化在本试点中拒绝，不未经复权就比较不同每股尺度。
5. 亏损和负EPS有效；非有限数、零股数、混合币值单位、未核验记录及同期间同时间歧义版本拒绝。方差为0返回结构化问题码，不除零。

上述null是**当前已审阅证据范围不足**，不意味着该公司当年没有公开股本信息，更不意味着原SUE策略理应持有现金。2015-09-30结果另用普通股利润尺度直接差分、`statistics.stdev`独立复核；恒定股数因子相消，绝对误差8.88e-16。相同台账重复运行结果一致，修改截止日之后的利润不能影响当期输出。`verification.json`保留这些检查与v6 manifest未变的哈希。

全部15个首次原报告不等于完整点时财务数据库。现有公告缓存按标题检查没有发现对应年份的修订/更正/更新/补充候选，但不能据此证明没有其他更正公告、追溯重述、快报或预告。台账保留试点范围声明；不把`first_reports`返回的`version_verified=false`自动升级成完整版本核验。

## 重建与验证

```powershell

python scripts/benchmark_sue_study.py --ledger .runtime/benchmark/sue-pilot-20261102/reviewed-ledger.json --evidence-root .runtime/benchmark/sue-pilot-20261102 --cutoff 2015-09-30T18:00:00+08:00 --output .runtime/benchmark/sue-pilot-20261102/asof-new.json
```

输出拒绝覆盖。台账契约：顶层`symbol`、`sources`、`cumulative`和`capital_proofs`；`sources`是来源ID到`document_path`、`sha256`、`source_uri`、`available_at`、物理`pages`的映射，路径须在证据根目录内。累计记录含`period_start`、`period_end`、`ordinary_profit_ytd`、`unit=CNY`、`basis`、`reviewed=true`、`available_at`与`sources`；股数证明含`start/end`、`shares`、`constant`、相同`basis`及审核/时间/来源字段。金额、EPS和股数用十进制字符串，时间带时区。`reviewed`是人工语义审阅的声明，哈希验证不替代该审阅。可按上表从公开原件重新摘录；仅取Git代码不足以声称复建了市场原档。
