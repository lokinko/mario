# 分红日历验收（2026-11-07）

本记录是本次开发验收，不代表线上已部署。产品行为见[买点观察](../buy-watch.md#分红日历)，长期分层与事务归属见[架构说明](../architecture.md#分红日历)。用户选择先使用公开结构化资料，暂不开启大模型。

## 实现范围

- 买点观察的“分红日历”默认合并当前公共目录和本账号自选，连续展示未来 30 天，支持范围切换、日期选择、翻页、只读轮询和手动/逐公司刷新。
- 登记、除息、派息日期各自独立；未定日期计划单列，取消/不分配排除。当前来源不提供可靠到账日，保持空值。公告日期与报告期分别处理，老报告期后来披露的真实实施日期仍有效。
- 通过东方财富公开结构化方案获取，不调用模型。后台沿用现有半小时循环，失败保留原计划及成功获取时间，不修改账号版本、个人名单、已实施分红、TTM 或资产。
- 公共计划缓存进入 PostgreSQL 整站备份。新增表幂等创建，没有账号数据转换；来源缓存可重新抓取。
