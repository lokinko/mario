# 2026-11-05 已有分红资料接入买点观察

## 整理范围与结果

本次按用户明确要求，将 2026-11-04 已采集的 210 只股票分红原件整理为在线观察可复用的公开初始化资料。原件位于 `.runtime/benchmark/raw-workflow-20261104/dividends-five-years-final/`，原始五年汇总及原件保持不变，不重新采集市场股票、不修改 benchmark 策略或成绩。

原始请求返回全部报告期，因此除 2021-11-04 至 2026-11-04 的五年汇总外，还能恢复更早的已实施历史。按原件核验后，可用股票 202 只、来源标为已实施的记录 3957 条（含送转和零现金方案，股息只计算现金分项），事件日期整体为 1991-03-11 至 2026-11-04；不同股票历史长度不同，不能将最早日期理解为全部股票均覆盖该日起。未来除息、预披露与未实施方案均排除。

梳理发现少数旧记录以年末作为报告期标签，实际除息日在同年较早月份。报告期属于来源分配方案标识，不能当作公告或实施时间；线上校验调整为校验日期格式、方案唯一性与除息日，继续按真实除息日计算。缺除息日、重复事件或金额无效仍阻止使用该证券历史。

## 交付与使用

- `server/data/watch-dividends-20261104.json`：随程序发布的公开资料包，包含 210 只股票的状态、202 份可用历史、来源 URL、原始采集时间与原件哈希。
- `scripts/prepare-watch-dividends.py`：离线原件核验与可复现整理；验证清单哈希、分页、证券身份、日期、精确十进制和重复事件。不依赖研究包的内部实现。
- `market_data/watch_archive`：运行时验证资料包并通过行情端口提供初始化历史；不读研究目录、不访问账号库。
- `outputs/买点观察_分红参考_20261104.csv`：本次已生成的 210 行清单，不进 Git；可用新增公开导出命令重新生成。包含 TTM 每股分红、5% 对应的最高参考价及待补查原因，不包含当前行情、BOLL 或完整买点结论。

参考清单复用 `models/watch::trailing_dividends`，未复制一套股息计算。例如截至 2026-11-04，招商银行为 2.016 元/股，对应 5% 门槛价格 40.32 元；这仅说明股息率条件，仍需行情日、日周 BOLL 和基本面核查。旧资料超过覆盖截止日后不能作为新行情日的完整分红依据。

资料包只匹配账号既有观察名单，不自动加入 210 家公司，不改变名单上限，不生成持仓或交易。账号没有独立分红资料时，首次检查使用内置历史并在原观察事务内落库；已有账号资料优先，仍按日更新、支持手动补查，失败保留原日期。没有新增持久化表或备份格式；失败和旧版本备份恢复仍沿用原有事务规则。
