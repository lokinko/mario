# 统一五年前复权价格库验收（2026-11-08）

本记录是本次实施与验收证据；长期契约以[市场数据](../market-data.md#统一公共价格库)为准。

## 目标与设计

解决持仓价格、收盘日及来源错配，以及多账号重复请求、网络失败后没有可复用行情的问题。用户明确要求前复权也用于持仓估值。五年趋势与持仓共用公开前复权序列；同日原价供股息率使用，私人数量、成本、成交、现金和过去日期的资产记录保持各自原值。

沿用[架构说明](../architecture.md)的模块地图、行情流（6.3）、观察流（6.5）及状态归属：`market_data/history` 只适配来源，`models/market/history` 校验精确序列及复权基准，`application/public_prices` 通过端口编排抓取，`db/public_prices` 负责完整版本原子写入与持久租约。账号估值和观察仍通过原应用流程及账号事务消费公开事实，公共仓储不读取租户资料。

## 替换与升级

启动事务幂等创建 `mario_market.price_histories`，按规范证券代码保存五个日历年的完整版本及刷新状态。没有账号 schema 或个人 JSON 备份版本升级。旧持仓不反向填充公共行情；成功取得公开资料后，在读取或后台检查时采用新口径。旧估值证据白名单仅服务历史恢复。

删除旧短窗口来源、独立持仓价格缓存、观察专属价格抓取和 Twelve Data 运行接口及设置。原加密密钥保留于账号存储及整站备份，不再读取；不删用户数据。新实现是唯一证券价格生产路径，汇率与分红计划能力继续独立运行。

失败处理：来源或校验失败保留上个完整版本，持久化失败尝试并退避；租约过期可恢复，旧令牌或实际收盘日倒退不得覆盖新版本。公共初始化失败回滚事务，不做部分升级。恢复采用现有整站 PostgreSQL 备份（含 `mario_market`）；个人 JSON 只恢复本账号及已采用的价格证据，不覆盖公共库。回退程序前保留新版整站备份和原主密钥，不删除新增公共表。

## 验证结果

- 架构检查及 4 项边界回归通过；公共库不依赖账号、应用流程或来源适配器。
- Rust：343 项通过，5 项联网测试默认忽略；fmt、Clippy（全部 targets，warnings 为错误）及构建通过。
- 前端：52 个测试文件、346 项通过（`--maxWorkers=2`）；TypeScript/Vite 构建及完整 `src` Prettier 检查通过。早期并行编译期间默认 worker 数的运行曾出现观察页测试超时，限制 worker 后全量通过，未调低断言或扩大测试超时。
- 领域与仓储覆盖精确金额、证券/日期/来源错配、五年闰日窗口、缺失复权、完整版本回退、两 Yahoo 主机滞后回退、同证券并发合并、持久租约令牌、失败保留、重启复用、旧收盘不可覆盖以及无使用证券停止刷新。
- 账号覆盖同日更正读取、两账号不同数量/成本使用同一公共价格、幂等读取、在途交易/删除保护及历史原值保留。

完整 `npm test` 已执行，但在 `scripts/server-artifacts.test.mjs` 复制夹具时被仓库现存缺失的 `scripts/test-financial.mjs`、`scripts/test-backup.mjs` 等入口阻塞（ENOENT），因此完整门禁未通过，后续原财务/桥接/Web 验收链未执行，不能用上述独立检查替代其结论。本次没有关闭或放宽该门禁，也未恢复不属于本任务的其他退役文件。部分当前文档指向这些既有缺失脚本或文档，新增价格文档链接均已核对。

## 独立 HTTP、重启与原生备份恢复

使用一次性 PostgreSQL 集群与本次构建的 API，创建两个测试账号，分别持有 `600941.SS` / `600941.SH` 的 10 / 20 股，原成本为 800 / 1600。未读取开发或生产数据。

经真实 HTTP 获取中国移动来源后，数据库仅有一条规范代码公共记录、1171 条实际日线；两个账号均读取 2026-11-06 的前复权收盘价 103.49，来源、实际收盘日与口径一致，精确单价字符串为 `103.49`。原数量与成本保持各自值。重复读取未推进账号版本。

记录公共 payload 指纹后，阻断行情网络、重启 API，两个账号仍能读取该公共版本；再对 `mario_auth`、`mario_market` 和两个租户 schema 执行原生 `pg_dump`，在另一一次性数据库 `pg_restore` 并阻断行情网络启动，数据仍一致，公共 payload 指纹保持不变。集群由既有测试工具自动删除。此验收不证明部署服务器可以连接外部供应商。

## 联网来源抽查

显式执行 `live_five_year_history -- --ignored --nocapture`：中国移动返回上市以来 1171 条（2022-01-05 至 2026-11-06），上证指数返回 1212 条（2021-11-08 至 2026-11-06），AAPL 返回 1255 条（2021-11-08 至 2026-11-06）。各自复权基准为最新有效收盘日；上市不足五年不补造历史。首次抽查中国移动与上证均使用东方财富，最终复验中国移动整组回退到 Yahoo，上证仍用东方财富，AAPL 使用 Yahoo。不同次请求实际来源可变化，各次保留真实来源及原价口径。
