# 外部策略第一批：规则核查与当前输入适配

目标是持续寻找更好的外部策略，不局限于现有策略邻域调参。本轮完成 9 个外部研究入口的来源与数据需求清单，其中 5 类规则能在声明改动后用现有输入试验，共比较 25 组参数；各类最优配置再经过正式 `bench-run` 复核。结果没有提高当前最高分 3.4959，不新增正式策略目录，也不修改现有最优参数。

## 范围和设计

沿用[架构说明的离线研究工具](../architecture.md#离线-benchmark-研究工具)及[模块边界](../module-boundaries.md)。不改输入、结果标签、评分公式或在线系统。策略只通过当期 `sample` 接收输入，临时策略仍经过静态检查、隔离子进程、8 位小数向下截断和统一成交/成本评分。

研究者用结果标签比较参数，但执行策略不读取结果标签。当前切片 `pools-v5-20261031` 共 148 期，科技 80、红利 68；2006–2017 有 84 期，2018–2025 有 64 期。参数按全段总分选择，分段仅为描述，**不是样本外**，没有做显著性检验或声称稳定超额收益。

来源与原规则的详细数据依赖集中在[持续研究清单](../benchmark-research.md)。本批是规则适配试验：窗口、资产池、长仓/现金限制、成本和持仓协议不同，不能用于确认或否定原论文报告的收益。

具体实现约束：

- 双动量：先按相对动量取前 N，再检查各入选股自身信号是否严格为正，每个预算为 `1/N`，不合格或名额不足的预算留作现金。中期动量为 `(1+m63)/(1+r20)-1`。没有把 63 日窗口称为 12 个月，也没有使用股票池外的债券或货币工具。持有到期，不附已有家族的止盈/网格。
- 时序动量：对动量与正波动都已知的成员，先按 `1/vol63` 计算全池预算；仅动量为正者投资，负向信号对应的预算保留现金，不将它重新分配给赢家。原时序动量研究的空头、跨资产期货与风险收益目标均未复现。
- MSCI 风格代理：分别对 `m63/vol63` 与 `中期动量/vol63` 做截面总体标准化，等权合成后再标准化；仅正分成员进入排名。得分映射为 `1 + min(3,z)`，用得分或得分乘选样日市值配仓。缺任一必要指标的股票不参加，常数截面时分数为 0、留现金。没有真实 6/12 个月窗口、三年周波动、利率、母指数权重、缓冲区或半年度重构，因此只是受其公开计算步骤启发的原型。
- 行业内低波代理：有行业信息时，各已知行业预算相等，内部只买低波候选；某行业没有合格候选的预算留现金，不推断缺失行业。红利池全无行业时在整个池内选低波，不伪造行业分类。这不是 beta，也不包含原论文的多空构建。持有到期。
- 逆方差预算：沿用现有中期动量行业分散选股，用入选股票 63 日波动的算术均值作为代理，预算为 `min(1,(目标/代理)^2)`；缺失或为 0 的个股波动按 2.8%。其余为现金，卖出执行沿用原家族。它没有计算原文的前一月组合已实现方差。

## 准入与去重

除逆方差版外，最高成绩都低于当前 Top-10 第十名的 3.0039。逆方差版若孤立作为新名字会进入前十，但它属于已存在的风险预算机制：当前 `trend_risk_budget` 的逆波动版为 3.3226，高于 3.2671。按“一种逻辑只保留最优参数”的要求，不另建逆方差目录，也不替换为更差参数。当前 15 种正式策略逻辑与 4 个基线的排名保持不变。

这些结果只说明本次有明确改写的配置在该切片上的表现；不意味着双动量、MSCI 指数或原论文方法普遍无效。外部原规则尚缺的数据和完整组合约束是后续工作，不能以完成这些容易运行的代理版替代。

## 执行与异常

临时策略与结果位于 `.runtime/benchmark/external-research-20261102/`，没有进入 `benchmark/strategies/` 或覆盖正式看板。各类最优配置经以下命令复核：

```powershell
. D:/Users/Desktop/home/code/.venv/Scripts/Activate.ps1
npm run benchmark -- bench-run --release .runtime/benchmark/pools-v5-20261031 --strategies .runtime/benchmark/external-research-20261102/candidates --out .runtime/benchmark/external-research-20261102/official-runs
```

此命令依赖本机缓存的临时原型，不能仅凭本次 Git 提交在另一台机器上直接重跑；未入榜候选按规范不提交策略目录。规则、参数范围与选择结果在本审计保留，需独立复现这批失败原型时按上节重建候选。正式网站看板继续完全由已提交的策略目录复现。

第一次正式执行发现既有 `generate_weights` 在传入相对策略路径时，先将子进程工作目录切到策略目录，却仍向子进程传入原相对路径，导致所有候选 `FileNotFoundError`，看板随后报缺少成绩。修复为启动前解析绝对路径，未放宽导入、输入隔离或执行限制。新增回归测试通过真实隔离子进程验证相对路径、输出及父工作目录保持。修复后五类均评分成功。

另有价格采集异常：Baostock 的单股两年后复权查询返回网络接收错误；Yahoo 能取得单股 22 年日线，但与现有切片的复权比值及交易日历有待解释的不一致。详见[长历史来源核查](../benchmark-research.md#长历史来源核查)。没有将这些观察自动接入正式输入，也未将不同供应商价格拼接。

本批保留扫描与正式评分的一致性核对，正式策略也在执行器哈希改变后重新评分；新增原型均未准入，网站看板的 Top-10 不变。原研究数据的成分代理、行业修订、公司行动及停牌估值限制继续适用。

验收：5 个最优原型在相同的 148 个样本上正式评分成功，扫描近似计算与正式总分的最大差为 `4.44e-16`；随后使用 `--force` 再次生成，5 个仓位文件和 5 个成绩文件均与第一次正式结果逐字节一致。正式目录、看板和成绩文件仍为 19 项，当前文档的全部名次与四位小数总分核对一致。`npm run test:benchmark` 的 101 个测试和架构检查的 7 个测试通过；本轮未改应用前后端、记账规则或公共数据契约，不运行无关的在线数据库集成验收。
