# 2026-11-08 只读证券报价账号锁核查

## 基线与已确认问题

本轮开始时 `main` 与已推送的 `origin/main` 为 `6eff1b0`，工作区干净。此前[架构债](../architecture.md#10-容量边界与已知架构债)记录行情网络等待占用账号锁；本轮先核对真实调用链，再由后端实现与测试角色分别审查，主负责人维护规范与最终验证。

`hosted::authenticate` 在认证、租户选择和版本检查后持有账号 advisory lock，直到 handler 完成。证券报价 GET 过去直接调用 `PortfolioService::security_quote`，外部供应商慢时同账号请求需要等待。该方法同时被 `verify_valuation` 复用，之后会登记公司行动和保存估值，因此不能无条件在共享方法内解锁，更不能把整个含仓储写入的用例放入解锁 Future。

## 本轮增量与边界

- [持仓应用用例](../../server/src/application/portfolio.rs)用一个私有来源选择函数保持原有 key 成功走配置供应商、读取失败走免费来源的行为；原 `security_quote` 仍持锁。
- 新 `preview_security_quote` 是 GET 专属入口：在既有账号锁内读取 key、选定供应商，仅端口查询 Future 经 `Database::without_account_lock` 执行；该 Future 不访问账号仓储。供应商成功或错误均先重获锁再返回。
- [HTTP 路由](../../server/src/http/portfolio.rs)仅将证券报价 GET 改为调用预览入口。核验估值、保存持仓、价格刷新、汇率查询与汇率更新没有本次解锁，不改财务事务、备份或 schema。
- 预览按开始时配置完成；中途删除／替换 key 不追溯取消已发供应商请求，后续查询使用新设置。旧预览不会回写新设置、持仓或每日资料，不自动换源重试。
- 没有新增“任意 revision 变化即 409”。只读结果可先于并发配置更改发生，且前端[请求政策](../../client/src/lib/requestPolicy.ts)不从证券／汇率报价 GET 接受资料版本。认证层仍返回结束时账号 revision；此头不是报价的全量资料版本，普通写入仍以原 `If-Match` 检查。
- 正常成功和错误返回会重获一层账号锁；取消整个预览 Future 保持既有 helper 的释放语义，不宣称客户端断线一定会立即取消服务端任务。连接和外层 guard 仍负责原有生命周期。

本轮沿用[架构 6.3](../architecture.md#63-行情与汇率)、[状态归属](../architecture.md#7-状态与事务归属)及[财务不变量](../architecture.md#8-关键不变量)，不引入新的运行角色、连接池或通用编排框架。现行契约同步到[行情](../market-data.md#只读证券报价与并发)、[模块边界](../module-boundaries.md#只读证券报价)与[模块索引](../README.md)，已知债只标注部分减轻。

## 验证范围

[应用回归](../../server/src/application/portfolio_quote_tests.rs)使用门控供应商与真实同账号独立 PostgreSQL 连接，检查等待期释放、返回前重获、外层 guard 释放后不残留锁，成功／错误／取消及配置并发更改，并保留原写路径持锁的反证。仅用同连接重入或普通快照读取不能证明 advisory lock 已释放。

[认证 HTTP 回归](../../server/src/hosted_quote_tests.rs)通过真实账号、认证 middleware、每请求独立数据库连接和本地假供应商核对路由、并发读取／写入与版本头，不启动公开行情后台任务。[客户端回归](../../client/src/api.hosted.test.ts)验证具体证券与汇率报价 GET 不接收未读取的新资料版本。

主负责人使用全新 `.runtime/security-preview-build` 构建生产改动，正常构建通过。新增文件的通配导入与 HTTP 调用换行分别被既有架构／格式检查拦住，随后改为显式导入及规定格式，没有放宽检查或新增豁免。

## 剩余事项

汇率查询以及价格／汇率刷新、保存持仓、核验估值仍可能等待供应商并持锁。写路径的进一步解锁需要冻结输入、重获锁后重验和原事务提交，不能直接复用只读语义；连接池、同步 SQL 与请求槽容量仍是独立边界。其他已记录的模型管理依赖、前端全局同步状态和手工跨语言契约也没有在本轮解决。

本轮不重新研究策略、不调整观察规则、不部署、不使用真实模型额度，不操作其他工作树或开发数据库。
