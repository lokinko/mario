- 完整 `npm test` 通过：前端 412 项；Rust 414 项通过、9 项原有显式 ignored；架构、格式、Clippy、构建、传输契约、HTTP、Web、模拟 Codex 桥接与财务备份恢复门禁通过，财务恢复核对 328 张表。
- 新增服务端及 HTTP 回归验证两个账号默认使用站点模型、冻结凭据与官方地址、已有个人配置优先、切换后个人凭据保留、拒绝改写站点地址/模型/密钥、拒绝个人删除站点密钥、停用后不可调用，以及预览/导出不含原始密钥、分析历史按账号隔离。
- 部署检查验证再次准备配置仍保留站点环境值，前端与 Rust 构建不继承 `OPENAI_API_KEY`。独立 `npm run test:startup` 通过：一次性宿主机部署目录的 `.env` 注入临时 API，注册账号读到站点来源和指定模型，服务日志与配置读取不含测试密钥；沿用原启动、重启及数据库生命周期验收。
- 使用本轮构建的二进制，在一次性 PostgreSQL 中注册两个空账号；真实密钥仅经临时进程输入与 API 环境注入，不保存到仓库、脚本、账号或报告。两个账号的 `GET /model-config` 均返回 `source=server`、`model=gpt-5.4`、`hasApiKey=true`，无需个人模型设置。
- 初次真实连接测试遭遇外部网络发送失败；随后单独检查 OpenAI 官方地址连通性，未认证访问返回预期 HTTP 401。重新验证时两个账号的 `POST /model-config/test` 均成功，耗时分别为 2903、2094 毫秒，配置读取和账号导出未包含密钥。没有将首次网络失败报告为成功，也未据连接测试推断搜索权限或投资建议质量。

完整问答的共享凭据冻结、独立 Agent 作业和持久化使用模拟 Agent 验证，本轮真实付费请求只做普通连接生成；先前的真实完整问答结果仍见[原接入记录](openai-api-smoke-20261116.md)，不把不同样本合称一次全链路真实验收。所有测试仅使用一次性数据库与空账号，没有读取开发或线上账本。

## 清理与交付边界

本轮使用独立的 `.runtime/openai-shared-build`（初次编译检查）及 `.runtime/openai-api-build`（完整门禁、启动和真实调用）作为 Rust 目标目录。全部依赖这些二进制的操作结束后，确认绝对路径在本仓库内且无进程占用，再执行 Cargo 清理并删除空目录；本轮验证脚本及两个临时日志随后删除。保留原 `server/target`、现有开发服务、数据库和其他任务的 `.runtime` 内容。一次性 PostgreSQL 集群和宿主机启动夹具均由测试工具停止、删除。
