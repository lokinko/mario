## 变更

`deploy` 显式同时传入 `--domain`、`--ip` 才调用独立 `setup-domain.mjs`；普通部署、`prepare`、管理命令不调用，只传一个参数在停服前拒绝。域名脚本管理服务名对应的 Nginx 站点，复用双域名证书，否则用 HTTP webroot 验证；备份、配置检查和失败回退不涉及账号数据库、主密钥或资产数据。手动 DNS 证书保持原续期方式。
