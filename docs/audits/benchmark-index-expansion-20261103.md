## 发布修正

实测锁定的Hugging Face SDK可能把大目录拆成多次提交。直接向主分支上传会短暂暴露文件未齐而manifest已更新的状态，本轮移除这条发布路径：

1. 从固定主分支提交创建专用临时分支，为日线目录配置LFS。
2. 完整上传后核对远端文件集合及内容标识；损坏或缺失不能提升主分支。
3. 获取完整祖先关系，核对暂存提交与原主分支，用非强制Git快进一次更新主分支。主分支已前进则保留临时分支，等待理解并整合其他更新。
4. 发布成功清理临时分支；失败可用保留的完整本地归档恢复。

日线与持续评测共享同一HF标签仓库主分支，两条Actions工作流改为共同使用 `benchmark-hf-main` 串行队列，避免正常重叠触发父提交冲突。

真实本地Git仓库测试覆盖多批提交快进、主分支并发前进和暂存内容变化；发布测试覆盖上传失败、暂存损坏、评分文件保留与旧布局移除。
