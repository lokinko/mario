# 2026-11-05 买点观察体验改进

## 体验与取舍

用户要求实际探索[慢慢变富](https://www.manmanbianfu.top/)，将有助于股息和买点观察的体验落实到 Mario。本次在浏览器体验其发现列表、[股息率网格](https://www.manmanbianfu.top/yield-grid)、股息状态筛选、指标说明，以及自选、收益和日历的公开空态；没有注册账号、写入该站数据或获取其私有内容。

| 观察到的优点 | 本次落地 |
| --- | --- |
| 同屏聚合身份、股息与价格，降低逐家公司查找成本 | 默认紧凑对比表，详细卡片可切换；同时显示行情日期 |
| 用不同股息率对应价格表达等待距离 | 服务端十进制生成 4/5/6/7% 参考价，标明 5% 观察门槛与是否满足股息条件 |
| 筛选、排序和自选入口靠近结果 | 点击统计筛选，名称/代码/理由搜索，当前持仓筛选，股息/日周距离/名称排序 |
| 轨道位置可视化与口径就地解释 | 日线和周线同时展示收盘、上下中轨及下轨 ±2% 阴影；说明就地展开 |
| 数据明细逐步展开，日期有组织 | 详情抽屉展示分红事件表、来源与真实交易；周内日期矩阵展示完整名单已保存观察 |
| 手机浏览不依赖宽表 | 窄屏列表改为带标签的小卡，筛选控件分行；详情复用现有抽屉与键盘焦点管理 |

保留用户选定的 TTM 已实施税前分红和总体标准差 BOLL(20,2) 口径，不用参考站的年度股息、预测值或其他周期替换。未取得已核验的行业、支付率、连续年度和未来除息资料，不从该站展示数字推断或填入生产数据。收益、现金和个人分红到账继续由原账本管理。

## 实现与数据边界

设计沿用[架构](../architecture.md)第 3 节依赖方向、第 6.5 节观察数据流和第 7 节状态归属。参考价只作为 `WatchRow.dividendPrices` 读取投影，由领域模型计算、仓储装配；不增加表、schema 版本或备份字段，不改写过去观察。缺失/零分红不产生正股息参考价，缺价格不判断已达；旧来源覆盖不足不能生成新依据。

前端按功能内职责拆分名单、轨道、详情与周内视图；移除原整段内联卡片与文字周报实现。业务计算和最终状态继续来自服务端，股息达标筛选使用服务端精确结果，避免显示舍入造成误判。筛选只影响当前列表，不隐藏周内完整名单、不改变后台任务；持仓筛选使用原账本当前数量，已清仓记录保留在交易明细中。

界面验收使用单独的临时页面和明确标记的模拟资料，未连接真实账号或行情；完成后删除临时页面和预览入口。效果图保留在本机 `outputs/watch-ui-20261105/`，其中手机详情展示参考价、日周轨道和资料日期；这些图不作为实际行情或账户事实。
