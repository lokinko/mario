# benchmark v2 免费来源可行性实测（2026-10-31）

这是一次性来源审计，不是已构建的数据集。目的是确认 [v2 行动指南](benchmark-v2-plan.md) 中三项“免费来源下的已知难点”能否用免费来源解决，以及在 2006–2025 年跨度上是否覆盖已退市公司。探测在本机临时目录进行，未写入采集目录、未上传 Hugging Face；Baostock 只在临时 uv 环境中试用，未加入项目依赖。

## 结论

| 难点 | 结论 | 依据 |
| --- | --- | --- |
| 申万行业时点归属 | 可行，有已知限制 | 申万官方逐股变更文件，含已退市公司 |
| 历史总市值 | 可行 | 东方财富股本变动历史（含公告日）× Baostock 未复权收盘价 |
| 已退市公司日线 | 只有 Baostock 可行，需要第三方依赖 | 腾讯、东方财富、Yahoo 不返回退市股票历史；新浪只返回最近 1023 根日线 |
| 中证红利历史成分 | 部分可行，需人工整理 | 新浪历史成分不完整；调样名单需从报纸公告逐年整理，再与当前官方成分对账 |

## 申万行业分类历史

- 来源：申万宏源研究的 [个股行业分类变动文件](https://www.swsresearch.com/swindex/pdf/SwClass2021/StockClassifyUse_stock.xls)（需浏览器 User-Agent，否则返回 508）。实测 1,166,848 字节，旧版 Excel（BIFF）格式，12,929 行，覆盖 5,934 只股票，字段为股票代码、计入日期、行业代码、更新日期。
- 已退市公司在内：乐视网 300104（2010-08-09 起 470202，2014-02-21 起 720301）、凯迪生态 000939 均有记录。
- 时点映射：2014-02-21 之前的旧版 23 个一级行业中，电子元器件（27）、信息设备（32）、信息服务（47）合起来对应之后的电子（27）、计算机（71）、传媒（72）、通信（73）。依据是 [申万 2014 版说明](http://vip.stock.finance.sina.com.cn/q/go.php/vReport_Show/kind/search/rptid/2128274/index.phtml)（“信息设备、信息服务调整为计算机、传媒、通信”）与 [长盛电子信息产业基金 2014-01-02 公告](https://epaper.stcn.com/paper/zqsb/html/2014-01/02/content_532854.htm)（电子信息行业由“电子、信息设备、信息服务”调整为“电子、计算机、通信、传媒”）。2021 版沿用这四个一级行业代码，见 [申万 2021 版说明](https://wxweb.swsresearch.com/swsreport/2021_08/328340.pdf)。
- 限制：文件是申万当前维护的历史，不是当年首次公布的版本。大量早期记录的更新日期为 2015-10，部分 2014-02-21 生效的记录更新于 2024-09，说明历史归属被事后修订过。数据集中保留更新日期，并标注“申万事后整理的历史归属”，不声称是当年公开时点的原始口径。

## 总股本与收盘价

- [东方财富股本变动接口](https://datacenter.eastmoney.com/securities/api/data/v1/get?reportName=RPT_F10_EH_EQUITY)：按证券返回每次变动的变动日、公告日、总股本、流通 A 股和变动原因。招商银行从 2002 年上市前股本开始；已退市的乐视网同样可查。选样日的总股本取“变动日和公告日都不晚于选样日”的最近一条，避免使用事后公告的股本。
- 收盘价：腾讯接口对招商银行 2007-12-28 返回收盘价 39.63，与 Baostock 未复权收盘价一致；但腾讯和东方财富 K 线接口对乐视网 2015 年均返回空，新浪 K 线接口只返回最近 1023 根且不能指定区间。
- Baostock：乐视网 2015-12-31 返回交易状态 0（停牌）、收盘价 58.80，凯迪生态 2007-12-28 同样有记录，并给出上市日 2010-08-12、退市日 2020-07-21。它还提供每日交易状态，可以直接区分停牌与缺失。Baostock 需要安装第三方 Python 包、使用自有 TCP 协议（不走 HTTP 代理）；再分发授权未审查。

## 中证红利历史成分

- [新浪历史成分页](https://vip.stock.finance.sina.com.cn/corp/go.php/vII_HistoryComponent/indexid/399922.phtml) 只返回 40 行，页面中的分页参数实际无效，且只列已剔除的成分，不能作为完整历史。
- 指数于 2008-05-26 发布，初始 100 只，编制方案见 [中国证券报 2008-05-13 公告](http://business.sohu.com/20080513/n256812020.shtml)。初始完整名单尚未找到免费原件。
- 年度调样名单可从报纸公告整理，例如 [2008-12-15 公告](https://paper.cnstock.com/html/2008-12/15/content_66612851.htm)（2009 年 1 月首个交易日生效，调入调出各 20 只）、[2014-12-01 公告](https://paper.cnstock.com/html/2014-12/01/content_467172.htm)（2014-12-15 生效）。2015 年以后的公告来源尚未确认。
- 重建方案：以仓库已有的 2026-10-26 官方当前成分为终点，按年度调样名单逐年倒推各年末成分，再用新浪的已剔除记录、初始名单（如能找到）交叉核对。倒推结果与核对点不一致的地方，就是遗漏的临时调整（退市、吸收合并等），逐条查公告补齐。核对完成前 `membership_verified` 保持 `false`。

## 待决事项

已退市公司日线只有 Baostock 能免费提供。可选方案：允许 benchmark 采集模块使用 `baostock` 作为隔离的可选依赖；或用标准库自行实现其协议；或在免费阶段接受退市公司行情缺口（会造成幸存者偏差，不建议）。
