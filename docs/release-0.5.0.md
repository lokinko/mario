# mario 0.5.0：围绕决策闭环的重构

发布日期：2026-09-10；功能验收：2026-09-09。

## 产品与可靠性

- 主导航收敛为“现在、决策、复盘”，原有辅助能力保留在“资料与工具”。
- 首页提供有依据的下一步，允许无需行动；移除以持仓数量和模型密钥加分的准备度分数。
- 研究提供风险、反证、复盘任务入口，编排开关收入高级设置，数据发送授权保持可见。
- 概率判断只展示明确成立/失效样本的误差和样本数，不包装成综合能力分；未填实际收益不再显示空的 `+%`。
- 本地快照与可选模型配置独立加载；账户与主要资料页失败可重试，财务保存失败保留输入。
- 决策规则未就绪时禁止冻结；迟到规则、历史分析与发送预览不覆盖当前编辑或选择。
- 请求有总时限；只重试读取的网络失败，写入不自动重放；云恢复通过应用数据刷新完成，不重载窗口。

## 架构

- 客户端应用壳与各领域页面分离，共享请求、格式、日期和小组件独立组织。
- 数据库按迁移、领域读写、同步格式/兼容、输入校验和快照计算拆分，保留 SQL、事务、公开接口和同步版本。
- 引入前端交互测试和源代码格式检查；产品宪章、架构与重构验收记录同步更新。

## 验证

- 0.5.0 全量 `npm test` 通过：20 项前端交互/传输测试、4 项认证页面测试、92 项服务端测试、2 项桌面测试，共 118 项；前端构建、格式与本地 API 鉴权冒烟通过。
- 服务端及桌面端严格 Clippy 通过；前端依赖审计无已知漏洞。
- 真实临时账号验证邮箱确认、公开回跳、密码恢复（链接与 OTP）、旧密码拒绝和新密码登录。
- 真实加密同步验证设备 A 上传、设备 B 导入恢复密钥并拉取，以及云端无明文标记；临时账号和数据清理完成。
- 隔离本地环境实际完成无账户、无模型的人工决策与复盘，确认原始判断保留并进入记忆目录。
- 桌面全部页面加载、手机 390px 逐页布局检查、780px 首页断点复查通过；浏览器控制台无错误。研究任务与本地发送预览可用，未调用外部模型。
- macOS arm64 DMG 与 Android arm64 APK 构建通过；macOS 签名、DMG 完整性和 APK v2/v3 签名验证通过。安装包预置公开云配置，不含特权密钥。
