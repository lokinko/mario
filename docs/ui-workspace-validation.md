# 紧凑卡片与列表工作台验收

验收日期：2026-10-14。本次为本地实现，未发布部署。

## 实现范围

- 默认打开投资持仓；统一页头、192px 桌面导航、浅色卡片与连续列表。
- 四项投资汇总按基础币种和持仓估值汇率折算，不含现金、不随筛选改变；缺失成本、汇率和交易分别提示，已清仓继续贡献已结算盈亏。
- 持仓详情、资产编辑和真实交易复用右侧抽屉；去除列表自动保存输入。抽屉约束焦点、处理 Escape、恢复原焦点、确认放弃草稿，保存失败保留输入。
- 现金余额列表、收支分组表单、含现金的每日记录；趋势默认收起。
- 问答历史移至侧栏，窄屏按钮展开；参考资料、复盘与长期记忆以列表为主，详情和编辑进入抽屉。
- 设置、账号、备份和登录统一卡片及控件。汇率保持独立、刷新收起，抽屉打开时隐藏。
- 未改变服务端 API、数据库结构及交易记账模型。
