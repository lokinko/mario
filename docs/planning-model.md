# 确定性风险与再平衡模型

mario 把可以由明确公式完成的工作留在本地规则层，大模型只解释结果、寻找遗漏和比较行动方案。本模型用于风险预算与再平衡提示，不预测具体证券价格。

本页记录仍在运行的辅助计算，不是[买点观察](buy-watch.md)的准入或仓位规则。用户无需先填写目标权重才能观察公司；本页的示例回报、风险预算和理论调仓金额不自动转成观察助手的买入数量。当前 `PortfolioPlan` 提供月结余、风险预算和再平衡，不输出投资目标达成率或退休资金预测；原目标管理模块已退役，旧目标数据的恢复边界见[备份版本](cloud-sync.md#备份版本)。

## 必要输入

持仓需要原币市值、资产类别、币种、估值日期和可选的目标权重。外币持仓使用统一汇率设置折算。缺少有效汇率、存在待确认拆合股或隔离交易链时，组合总值、集中度和再平衡不可计算，其他持仓继续显示原币金额。数据问题统一由 `valuation::issues` 返回问题码、持仓 ID、币种与一句说明。存款待核对保留已记录余额并继续计算。估值日期可以不同，较旧日期、参考价和手工估值只显示日期及来源，不作为计算门槛。

## 资产类别假设

长期示例假设如下：

| 资产类别 | 年化回报假设 | 年化波动假设 |
|---|---:|---:|
| 现金 | 2.0% | 1.0% |
| 债券/固收 | 3.5% | 6.0% |
| 股票/权益 | 7.0% | 20.0% |
| 基金 | 5.5% | 14.0% |
| 黄金 | 4.0% | 18.0% |
| 另类 | 4.5% | 20.0% |
| 其他 | 3.0% | 20.0% |

组合波动率使用“完全分散”与“完全相关”估计的加权混合。这样做是为了避免在只有粗粒度资产类别时伪造精确的相关系数。没有持仓时，系统使用固定的稳健占位假设。

## 风险预算

压力损失估计取组合年化波动率的两倍，上限 100%，与从最大可承受回撤开始调整的风险容量比较。调整依次执行：

- 投资期限不超过两年时，容量上限为 8%；
- 已填写正数月支出且应急资金不足三个月时，容量乘以 0.7；
- 已填写正数月收入且负债超过一年收入时，容量再乘以 0.85。

`exactMonthlySurplus` 按保存的精确月收入减月支出计算，负数截为 0；`monthlySurplus` 是其显示投影，不表示已安排的买入金额。

没有持仓时，系统不会声称风险处于边界内或边界外。该指标是预警尺度，不是 VaR、最大回撤预测或监管意义上的风险测量。它的作用是让组合风险与用户约束发生显式对话。

## 再平衡

只有当全部持仓目标权重合计为 100%（容差 1e-8）时，系统才计算再平衡。实际权重与目标权重偏离不足 3 个百分点时不触发动作，避免为微小漂移制造换手。

计划以 `rebalancingBlockedBy` 表达不计算的原因；目标权重未闭合时返回 `invalidTargetWeights` 和 `targetTotalPct`，不影响其他计算。未平仓期权及其标的列入 `excludedHoldingIds`，不产生普通再平衡动作；其他持仓仍以完整组合总值为分母，不对剩余目标重归一化。`asOf` 是参与完整组合计算的最早估值日期，包括仅排除动作的持仓。

金额使用精确十进制计算；JPY 舍入为整数，其他基准币种保留两位，半值向远离零的方向舍入。返回的 `exactAmount` 是精确金额字符串，number 金额仅作显示投影。该金额表示回到目标权重所需的理论增减量，不考虑税费、最小交易单位、流动性和账户限制，是复核提示，不是自动交易指令。

## AI 使用约束

AI 可以解释上述风险、比较方案和寻找冲突证据，必须明确示例假设与未知项，遵守用户的财务安全边界；不能把压力损失当作收益或最大回撤预测，也不能在缺少可信数据时编造实时事实。冻结的事实卡以 `facts.dataIssues` 传入问题码、影响持仓与受影响的计算范围（`affects`），再平衡阻止原因和 `rebalancingExcluded` 排除持仓也在其中。AI 不得对不可用持仓引用精确金额；再平衡受阻时不得给出组合调仓金额；引用价格或估值须说明日期。动作不强制固定措辞，结构、证据 ID 和原值引用必须校验。

## 实现与验证依据

- [规划计算及单元测试](../server/src/planning.rs)定义资产类别假设、容量调整、目标合计容差、3 个百分点触发条件和金额舍入；`rebalancing_requires_complete_targets_and_ignores_small_drift`、`empty_portfolio_does_not_claim_risk_alignment` 覆盖门槛与空组合。
- [快照组装](../server/src/db/snapshot.rs)、[精确会计](../server/src/db/amounts.rs)与[估值问题规则](../server/src/valuation.rs)决定完整组合口径；[期权测试](../server/src/db/options.rs)中的 `open_options_exclude_only_the_contract_and_its_underlying` 覆盖排除自身动作但保留组合分母和最早日期。
- [仓储测试](../server/src/db/tests.rs)中的 `incomplete_target_weights_only_block_rebalancing` 与 `old_cash_and_security_dates_do_not_block_rebalancing` 区分缺目标与价格日期；[事实卡](../server/src/context/fact_sheet.rs)将可用金额及结构化影响范围冻结给 AI。
