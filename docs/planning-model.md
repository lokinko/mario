# 确定性风险与再平衡模型

mario 把可以由明确公式完成的工作留在本地规则层，大模型只解释结果、寻找遗漏和比较行动方案。本模型用于风险预算与再平衡提示，不预测具体证券价格。

## 必要输入

持仓需要原币市值、资产类别、币种、估值日期和可选的目标权重。外币持仓使用统一汇率设置折算。缺少有效汇率时，组合汇总、压力损失和再平衡暂停；估值日期不一致时提示核对价格口径。

## 资产类别假设

长期示例假设如下：

| 资产类别 | 年化回报假设 | 年化波动假设 |
|---|---:|---:|
| 现金 | 2.0% | 1.0% |
| 债券/固收 | 3.5% | 6.0% |
| 股票/权益 | 7.0% | 20.0% |
| 基金 | 5.5% | 14.0% |
| 黄金 | 4.0% | 18.0% |
| 另类 | 4.5% | 20.0% |
| 其他 | 3.0% | 20.0% |

组合波动率使用“完全分散”与“完全相关”估计的加权混合。这样做是为了避免在只有粗粒度资产类别时伪造精确的相关系数。没有持仓时，系统使用风险倾向对应的保守占位假设。

## 风险预算

压力损失估计暂取组合年化波动率的两倍，并与用户填写的最大可承受回撤比较。以下因素会自动压低风险容量：

- 投资期限不超过两年；
- 应急资金不足三个月；
- 负债余额超过一年收入。

没有持仓时，系统不会声称风险处于边界内或边界外。该指标是预警尺度，不是 VaR、最大回撤预测或监管意义上的风险测量。它的作用是让组合风险与用户约束发生显式对话。

## 再平衡

只有当全部持仓目标权重合计处于 99%—101% 时，系统才计算再平衡。实际权重与目标权重偏离不足 3 个百分点时不触发动作，避免为微小漂移制造换手。

金额表示回到目标权重所需的理论增减量，不考虑税费、最小交易单位、流动性和账户限制。它是复核提示，不是自动交易指令。

## AI 使用约束

AI 可以解释上述风险、比较方案和寻找冲突证据，必须明确示例假设与未知项，遵守用户的财务安全边界；不能把压力损失当作收益或最大回撤预测，也不能在缺少可信数据时编造实时事实。
