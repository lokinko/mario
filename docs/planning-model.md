# 确定性规划模型

知衡把可以由明确公式完成的工作留在本地规则层，大模型只解释结果、寻找遗漏和比较行动方案。本模型用于目标规划、风险预算与再平衡提示，不使用实时行情，也不预测具体证券价格。

## 必要输入

目标账户需要：

- 目标金额与目标日期；
- 已经投入的金额；
- 计划每月投入金额；
- 优先级。

持仓需要原币当前市值、资产类别、币种、估值日期和可选的目标权重。外币持仓还需要用户填写“1 单位持仓币种折合多少基准币种”。目标账户的“已投入金额”由用户明确填写，系统不会擅自把同一持仓分配给多个目标。

所有持仓先按财务档案中的基准币种折算。任何外币持仓缺少有效汇率时，组合总值、集中度、目标路径、压力损失和再平衡计算全部暂停；系统不会直接相加不同币种，也不声称用户汇率已经过市场数据核验。估值日期不一致会产生显式风险提示，并阻止组合检查点归因。

## 目标模拟

每个目标执行 2,000 次固定种子的月度路径模拟。固定种子使同一组输入产生可重复结果，便于用户理解“修改投入计划导致了什么变化”，而不会因随机刷新得到不同答案。

长期示例假设如下：

| 资产类别 | 年化回报假设 | 年化波动假设 |
|---|---:|---:|
| 现金 | 2.0% | 1.0% |
| 债券/固收 | 3.5% | 6.0% |
| 股票/权益 | 7.0% | 20.0% |
| 基金 | 5.5% | 14.0% |
| 黄金 | 4.0% | 18.0% |
| 另类 | 4.5% | 20.0% |
| 其他 | 3.0% | 20.0% |

组合波动率使用“完全分散”与“完全相关”估计的加权混合。这样做是为了避免在只有粗粒度资产类别时伪造精确的相关系数。没有持仓时，系统使用风险倾向对应的保守占位假设。

输出包括：

- 模拟路径中达到目标的比例；
- 第 10 百分位和中位终值；
- 在保守规划回报下需要的月度投入；
- 当前月度投入与所需投入之间的缺口。

保守规划回报取组合期望回报减去 0.75 倍波动率（最低不小于 -2%），用于降低“平均路径刚好达标”造成的虚假安全感。模拟未包含税费、通胀、资产相关性突变、收益分布肥尾、未来收入变化和临时取款。因此“模拟达成率”只能用于方案比较，不能解释为真实世界的精确成功概率或收益承诺。

## 风险预算

压力损失估计暂取组合年化波动率的两倍，并与用户填写的最大可承受回撤比较。以下因素会自动压低风险容量：

- 投资期限不超过两年；
- 应急资金不足三个月；
- 负债余额超过一年收入。

没有持仓时，系统不会声称风险处于边界内或边界外。该指标是预警尺度，不是 VaR、最大回撤预测或监管意义上的风险测量。它的作用是让组合风险与用户约束发生显式对话。

## 再平衡

只有当全部持仓目标权重合计处于 99%—101% 时，系统才计算再平衡。实际权重与目标权重偏离不足 3 个百分点时不触发动作，避免为微小漂移制造换手。

金额表示回到目标权重所需的理论增减量，不考虑税费、最小交易单位、流动性和账户限制。它是复核提示，不是自动交易指令。

## AI 使用约束

AI 可以基于上述结果解释风险、提出多方案和寻找冲突证据，但必须：

- 明确模型假设和未知项；
- 不把模拟达成率称为保证；
- 不覆盖用户的财务安全边界；
- 不在缺少可信数据时编造实时事实；
- 给出调整投入、期限、目标金额和风险暴露等多个选项，而不是只建议提高风险。
