# 买点观察中的研究与讨论方法

当前产品目标见[产品主线](product-vision.md)，观察公式和数据口径见[买点观察](buy-watch.md)。本文说明如何围绕具体公司展开讨论，不要求用户先完成完整财务规划或研究表单。

左侧“投资方法论”是账号可编辑的提示词，正文不能为空，最多 4000 个字符。未保存过时读取服务端初始范本；“使用初始范本”只填入编辑区，保存后才生效。保存的正文用于之后每轮分析并进入预览指纹，已开始的分析继续使用冻结版本。本文说明讨论方法，不替换账号正文或代码内范本；系统的数据授权、来源和输出校验独立于提示词。

## 先分清观察条件与投资判断

确定性计算按当前账号保存的观察规则回答“是否进入关注区间”：默认是 TTM 税前股息率 ≥5%、日线 BOLL 下轨价格 ±2%、周收盘价 ≤ 周线 BOLL 中轨，股息、日线、周线三项同时满足。用户可调整门槛、日周参考轨、比较方式和偏移；讨论应使用当前配置，并按各条历史观察冻结的规则解释当时结果，不能把默认值当作所有账号的现行门槛。研究负责回答“为什么值得长期持有、这个价格对我是否合适”；满足观察条件后仍可能继续等待。

讨论围绕四件事展开：

1. **长期持有理由**：需求是否仍稳定，公司经营和现金流是否支持原判断，最有力的反方证据是什么。
2. **分红持续性**：实际派息的来源、普通与特别分红的区别，以及是否有削减或不可持续的证据；TTM 不代表未来承诺。
3. **价格条件**：日线、周线、股息率分别距离门槛多远，观察日期是什么；技术位置不能单独证明低估。
4. **个人适用性**：当前持仓、现金、近期真实买卖与分红是否改变判断，是否与先前交易理由矛盾，下一步还需等待什么证据。

这些是讨论线索，不是每次必须填写的问卷。讨论不从观察规则直接推断精确买入数量、资金比例或加仓频次；用户自己填写的股息网格另按[网格测算](buy-watch.md#股息网格与价差测算)比较单轮情景，不构成系统决定的真实交易。

## 用真实记录减少重复解释

持仓和交易只在原账本维护。问答按授权使用每项持仓最近 20 笔真实交易及已录入总笔数，并携带现金余额与核对状态；原始成交价按成交时股数口径保留，跨拆合股不能直接比较。未持有的观察公司不需要创建虚拟持仓。

风险和再平衡属于已有辅助计算，假设及限制见[确定性模型](planning-model.md)。不能把未填写的目标权重变成观察助手的使用前置条件，也不能把示例风险假设解释为当前买点策略的仓位规则。

## 证据与未知项

外部事实保留来源、日期和口径，区分原文、供应商数据、计算结果与模型推断。资料不足时明确哪些判断尚无依据；只影响对应计算或结论，不要求先补齐所有资料才能观察其他公司。

AI 只能引用本次授权、冻结的个人事实和研究证据；网页搜索沿用用户保存的问答预设，当前模型接口支持时生效。来源引用存在不等于内容已核验，历史模型答案也不提升为事实。授权边界见[AI 数据边界](ai-data-boundary.md)，引用契约见[研究证据](research-evidence.md)。

## 周末复盘

回看本周哪些公司进入或离开关注区间、哪些长期持有理由发生变化，以及下周等待什么。用户可以在“复盘记录”保存自由文字，必要时主动整理为个人规则；不强制概率、纪律评分或下次复盘日期。

已有复盘和个人规则不自动进入问答，需要时由用户带入问题。收益是结果信息，不能仅凭最近上涨证明策略有效，也不能据一次亏损否定整个判断。以是否减少重复检查、用上真实交易、帮助说明等待条件来评价助手的作用。

方法论接口为 `GET/PUT /api/investment-methodology`，写入正文为 `{prompt}`，返回已保存正文、初始范本和长度限制；认证、账号隔离和 `If-Match` 沿用通用请求路径。账号仓储在现有 `settings` 保存 `investment.methodology`，随个人备份恢复；读取未保存账号不会隐式写入范本。实现见[方法论编辑器](../client/src/features/methodology/InvestmentMethodology.tsx)、[正文契约](../server/src/models/methodology.rs)、[设置仓储](../server/src/db/settings.rs)及[冻结准备](../server/src/application/analysis.rs)。已有[页面回归](../client/src/features/methodology/InvestmentMethodology.test.tsx)和[功能 API 验收](../scripts/test-functional-api.mjs)覆盖保存、失败草稿、范本和长度校验，冻结版本由分析用例内测试覆盖。
