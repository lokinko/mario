# 知衡投资方法论

## 产品原则

知衡优化的是“长期目标实现概率”，而不是交易频率、浏览时长或短期收益排名。

核心闭环：

```text
财务底座 → 目标与期限 → 资产配置 → 独立研究 → 仓位决策 → 复盘校准
     ↑                                                    │
     └──────────────── 持续更新约束与认知 ────────────────┘
```

## 六层检查

### 1. 财务底座

先检查现金流、应急资金、债务和不可承担损失的资金。应急资金不足时，不以提高风险资产收益作为解决方案。

### 2. 目标与期限

每笔资金必须属于安全、目标或成长账户。目标日期和刚性程度决定风险容量。

### 3. 资产配置

先决定整个组合的风险来源，再研究具体标的。识别集中、相关性、流动性和期限错配。

产品中的目标情景、风险预算和再平衡偏差由本地确定性规划模型计算，再交给 AI 解释和反驳。计算假设、限制与触发阈值见 [确定性规划模型](planning-model.md)。

### 4. 独立研究

回答资产是什么、收益从哪里来、市场为什么可能定错价、最强反方观点是什么，以及当前价格隐含什么预期。

### 5. 仓位决策

判断决定是否进入候选，赔率决定潜在吸引力，犯错成本决定仓位上限。每次主动判断必须预先写下证伪条件。

### 6. 复盘校准

区分好过程与好结果，记录预测概率、实际结果和规则违反情况。避免因一次幸运盈利强化错误流程。

原始决策快照与复盘记录必须分开保存，复盘不能覆盖当时的逻辑、置信度、仓位和证伪条件。当前产品用 Brier 思路计算简化校准分：逻辑成立记为 1、失效记为 0、部分成立记为 0.5。该分数只用于长期训练概率意识；样本很少时不应被解释为投资能力排名。

## AI 的角色

AI 适合：

- 把模糊问题转化为待验证假设
- 寻找遗漏和反方证据
- 比较多个方案及其适用条件
- 从历史决策中发现重复错误
- 把组合风险解释成行动清单

AI 不应该：

- 编造未接入的实时行情或公司事实
- 承诺收益或给出“稳赚”结论
- 用复杂叙事替代风险和估值分析
- 直接覆盖用户预设的风险边界
- 以短期价格结果评价决策质量

## 产品反馈指标

优先衡量应急覆盖、目标匹配、集中度、计划外交易、决策卡完整度、预测校准、复盘完成率、费用与换手，而不是用短期收益率作为唯一分数。
