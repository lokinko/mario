# 知衡投资方法论

## 产品原则

知衡优化的是“长期目标实现概率”，而不是交易频率、浏览时长或短期收益排名。

核心闭环：

```text
财务底座 → 目标与期限 → 资产配置 → 独立研究 → 仓位决策 → 复盘校准
     ↑                                                    │
     └──────────────── 持续更新约束与认知 ────────────────┘
```

## 六层检查

### 1. 财务底座

先检查现金流、应急资金、债务和不可承担损失的资金。应急资金不足时，不以提高风险资产收益作为解决方案。

### 2. 目标与期限

每笔资金必须属于安全、目标或成长账户。目标日期和刚性程度决定风险容量。

### 3. 资产配置

先决定整个组合的风险来源，再研究具体标的。识别集中、相关性、流动性和期限错配。

产品中的目标情景、风险预算和再平衡偏差由本地确定性规划模型计算，再交给 AI 解释和反驳。计算假设、限制与触发阈值见 [确定性规划模型](planning-model.md)。

组合计算必须先统一计量单位。财务档案指定基准币种；外币持仓保留原币市值，并用用户填写的估值日汇率折算。缺少汇率时，系统停止总市值、集中度、目标模拟和再平衡计算，而不是直接把不同币种相加。估值日期不一致时，系统提示时间错位并拒绝冻结周期检查点。汇率和日期仍是用户声明值，不能冒充已核验市场数据。

### 4. 独立研究

回答资产是什么、收益从哪里来、市场为什么可能定错价、最强反方观点是什么，以及当前价格隐含什么预期。

事实必须进入证据账本：保留准确标题、发布方、来源层级、HTTPS 链接、资料日期、支持或反驳关系和限制。来源层级只是“离原始事实多远”，不是对内容正确性的保证。AI 只能引用本次发送前预览中出现的证据；用户整理的摘要仍需回到原始链接核验。详细契约见 [研究证据与引用](research-evidence.md)。

最终 AI 分析不能把事实、推断和未知混成一段自由文本。模型必须为每条主张声明来自用户数据还是研究证据；研究证据引用由服务端按本次授权 ID 校验，未知引用会被拒绝。该检查能约束来源边界，但不能替代用户阅读原始资料或判断推理是否合理。

### 5. 仓位决策

判断决定是否进入候选，赔率决定潜在吸引力，犯错成本决定仓位上限。每次主动判断必须预先写下证伪条件，并逐条确认当前有效个人规则是“遵守、偏离还是不适用”。偏离规则必须在行动前留下理由，不能等结果出现后再合理化。

### 6. 复盘校准

区分好过程与好结果，记录预测概率、实际结果和规则违反情况。避免因一次幸运盈利强化错误流程。

原始决策快照与复盘记录必须分开保存，复盘不能覆盖当时的逻辑、置信度、仓位和证伪条件。当前产品用 Brier 思路计算简化校准分：逻辑成立记为 1、失效记为 0、部分成立记为 0.5。该分数只用于长期训练概率意识；样本很少时不应被解释为投资能力排名。

除了单笔决策复盘，用户还应按固定周期检查整个投资系统：是否按计划投入、是否违反规则、风险边界是否变化、哪些经验可以跨情境复用。周期复盘保存当时的组合与方法快照，避免以后用新状态解释旧行为。可复用经验应转成包含“触发条件、具体行动、依据”的个人规则；规则修订产生新版本，不能覆盖历史。产品只比较遵守与偏离样本的过程评分关联，不把短期收益或小样本相关性解释成规则有效性的因果证明。详细数据契约见 [复盘与规则闭环](review-and-rules.md)。

组合检查点用于回答“这段时间组合为什么变了”，而不是直接制造一个收益率数字。用户用不可变流水分别记录外部入出金、分红利息、费用税费和买卖换手；系统按相邻估值日自动汇总，再用期末总市值减期初总市值并扣除净外部现金流，得到需要继续解释的估值/数据残差。日期完整时还会给出 Modified Dietz 期间近似回报，但它不是时间加权收益率；在缺少可信价格、汇率和现金流时点估值时，不用于能力排名或收益承诺。详细定义与限制见 [组合变化归因](portfolio-attribution.md)。

## AI 的角色

AI 适合：

- 把模糊问题转化为待验证假设
- 寻找遗漏和反方证据
- 比较多个方案及其适用条件
- 从历史决策中发现重复错误
- 把组合风险解释成行动清单

AI 不应该：

- 编造未接入的实时行情或公司事实
- 承诺收益或给出“稳赚”结论
- 用复杂叙事替代风险和估值分析
- 直接覆盖用户预设的风险边界
- 以短期价格结果评价决策质量

## 产品反馈指标

优先衡量应急覆盖、目标匹配、集中度、计划外交易、决策卡完整度、预测校准、复盘完成率、费用与换手，而不是用短期收益率作为唯一分数。
