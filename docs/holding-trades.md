# 从成交明细计算持仓

“我的情况 → 投资持仓”保留数量、平均成本、当前价格、市值和浮动盈亏总览。使用“记录买入”从零持仓开始；每项持仓的“交易明细”可展开查看或追加买卖。基本字段为成交日期、账户、数量和单价；手续费及税费合计、券商成交编号和备注折叠为选填项。每项持仓对应同一账户、同一证券和币种，不同账户应分别建仓。

保存成交与更新持仓在同一数据库事务内完成。买入费用计入成本，卖出按交易日期、同日录入顺序使用加权平均成本扣减，卖出费用从收入扣除。页面分别展示浮动盈亏与已录入期间的已实现盈亏。新日期的成交单价带入为手动参考价格，用户应核对并更新当前价格；它不是自动市场报价，也不会被标为已核验行情。买卖不会自动修改银行存款或券商现金余额，请按实际余额更新现金。

已有数量与总成本的持仓在首次记交易时冻结一条期初余额。期初日期之前不能回填成交，以免重复计算已有数量；如果需要从完整历史重建，应从新的零持仓录入真实历史成交。缺少数量或总成本的旧记录需先补齐。期初数据仅是用户声明，不代表券商明细已核验。

交易持仓的数量、成本、币种、资产类别及证券代码不能被旧的编辑接口覆盖，当前参考价格、名称与目标权重仍可修改。误录使用“撤销误录”，填入原因后追加撤销记录，保留原成交并重算全部有效明细。撤销或回填导致历史任一时点超卖时，整次操作拒绝并回滚。交易持仓可卖出清仓，不能通过删除持仓移除交易链。

请求编号支持同一内容安全重试；同一账户的券商成交编号防止重复录入，撤销后仍保留该编号。客户端持仓版本检查避免旧表单覆盖新资料。交易链与每日资产历史、备份及加密同步一同保存；同步格式升级为 v15，仍支持 v1–v14 的旧包，导入时验证明细关联并重算数量、成本。

当前是根据券商成交记录手动录入，未接入券商 API 或原始交割单自动导入。现有“组合流水”金额记录不包含数量，不能直接用来重建持仓；该流水的 CSV 导入保持原有归因用途。本持仓明细暂不自动写入组合流水，不重复计入组合换手或费用汇总。分红、拆股、送股、转托管等公司行动尚未进入本持仓计算口径。冻结的组合检查点保留创建时的持仓，不因追加或撤销明细而重写。
