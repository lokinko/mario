# 分析看板

主导航的“分析看板”（`#dashboard`）汇总已经保存的个人资料，不调用模型即可查看：

- 总资产、净资产、负债率、现金和投资资产；
- 月结余、储蓄率、目标计划投入后的月余量、备用金覆盖与缺口；
- 每日资产趋势，支持 30 天、90 天、1 年及分页加载全部历史；
- 按资产类别或记账币种展示配置，以及最大单项、前三项、外币持仓占比；
- 逐项市值、成本、浮动盈亏、目标偏差、估值日期和价格来源，可按市值、浮盈或配置偏差排序；
- 目标筹备进度、模型达成率、投入缺口、保守与中位情景金额，以及风险预算与再平衡提示；
- 可调整投资下跌及外币贬值幅度的假设情景；
- 最近一期冻结组合的总变化、净外部现金流、估值残差与 Modified Dietz 期间近似回报；
- 按发生日期汇总入出金、分红利息、费用税费与内部买卖额；
- 决策复盘进度、到期未复盘、过程评分及规则遵守情况。

“继续做整体分析”只把整体资产与投资问题预填到问答页。用户仍在原有问答流程中选择资料范围并主动发起分析。

## 计算口径与数据缺口

总资产是持仓中的现金与非现金市值之和；净资产扣除档案负债。备用金属于现金中的预留部分，不再次计入总资产。现金扣除备用金后余额不能自动解释为可以投资的金额。目标金额不再次叠加到持仓资产中。

缺少汇率时不展示伪完整的总值、净资产、配置比例、总浮盈或情景金额。单项已能折算的市值仍可查看。零收入、零支出和零总值不作为比率分母。负净资产和负月余量保留其真实符号。

浮动盈亏只包括非现金且累计成本大于零的持仓。成本零值同时是未填写的默认值，因此按成本未知处理；显示覆盖项数及投资市值的成本覆盖率。市值为零但成本已录的持仓仍体现全额亏损。市值与成本均按当前汇率折算，不能区分历史成本汇率、已实现收益、分红和税费。

目标权重合计为 100% 后才显示逐项配置偏差。目标进度条显示已筹备比例，模型达成率另行标注。模拟金额、压力损失及可调整情景都是模型或用户假设，不是收益或概率预测。外币占比使用持仓记账币种，不代表基金底层资产敞口。

每日余额的沿用值和跨币种分段沿用每日追踪的规则；金额增长不视为投资收益。冻结快照与当前余额分开显示，基准币种变化时不跨口径比较。创建下一条快照前必须成功读取既有记录，避免读取失败被解释为尚无基线。

流水接口最多返回最近 500 笔，因此区间统计只覆盖已载入记录，达到上限时明确提示可能不完整。不同冻结基准币种不混加；冲正负值计入其发生日期所在区间，不静默删除原流水。内部买卖额不计作外部现金流。

补充记录加载失败时显示不可用并可重试，不把失败显示为零。保存、远程更新和资料版本变化会刷新分析记录，并忽略已失效的请求响应。

## 验证

前端测试覆盖现金与备用金不重复计算、成本缺口、多币种折算、零分母、全额亏损、目标月度投入超额、市场与汇率冲击的叠加、流水冲正与日期边界，以及页面导航、情景交互、独立加载失败与重试。
