# 从 AI 分析到用户决策

AI 分析只有进入“提出假设—人工判断—保存记录—后续复盘”的闭环，才会帮助用户积累能力。mario 不会把报告阅读量当作进步，也不会让模型的行动建议直接变成正式决策。

## 交互契约

```text
结构化 AI 分析 → 用户选择一条行动 → 生成待确认草稿
                                      ↓
              用户在一个文本框中补充观点、顾虑与思考
                                      ↓
                       点击保存决策 → 原始文字记录
                                      ↓
                              后续复盘与经验修正
```

点击“转为决策草稿”只会复制以下文字线索：

- 当前综合判断、所选行动及其理由；
- 报告中已经列出的风险和未知项；
- 所选行动与报告给出的复盘/证伪条件；
- 原分析 ID 和行动序号，用于以后追溯来源。

新增决策只需填写一段非空纯文本，可自由描述观点、顾虑和思考。AI 草稿中的行动理由、风险、未知项和重新考虑的条件会合并到同一个文本框，用户可以补充或改写。点击“保存决策”后才写入数据库，换行和原文均保留；无需另外填写收益、置信度、仓位、复盘日期，也不强制逐条确认个人规则。

## 数据完整性

正式决策保存时，服务端会检查文字不是空白；若关联 AI 分析，还会检查来源分析确实存在于本地 `analyses` 表。来源 ID 和行动序号保存在不可变决策载荷中，不依赖客户端标签，也不会在复盘时被覆盖。决策日志中的来源标签可以按 ID 重新打开完整分析，不受最近历史列表条数限制。旧版本没有来源字段的决策仍可读取，结构化历史记录会以完整文字展示。纯文本记录不设置到期复盘日，不进入到期决策提醒。

分析记录与决策记录承担不同职责：

- 分析记录保存模型当时看到的上下文审计、结构化结论和工作流轨迹；
- 新增决策记录保存用户最终接受和修改后的完整文字，以及可选的原分析来源；已有结构化记录保留原字段；
- 两者有关联不等于两者相同。决策卡明确标记“已由用户确认”，但这不代表分析事实已经被外部核验或投资结果有保证。

云同步以加密数据包同时同步分析和决策，因此来源关系无需新的云端明文元数据。模型密钥、登录令牌与恢复密钥仍不进入同步包。

## 安全边界

- 模型不能调用保存决策接口，也不能执行交易；
- 未通过结构化输出校验的分析不能生成这个入口；
- 草稿内容始终可编辑，保存时仅要求文字不是空白；
- 服务端拒绝引用不存在的分析，避免伪造来源；
- 来源标签只说明文本从何而来，不代表正确性、适当性或收益承诺。
