# 账号与数据同步

账号和业务数据都保存在自建服务器的 PostgreSQL 中，设备之间通过数据版本同步。部署见 [自建部署指南](self-hosting.md)。

## 协议

1. `POST /api/auth/register`：邮箱、密码；公开注册，无需邀请码。请求只接收邮箱与密码，其他字段会被拒绝。
2. `POST /api/auth/login`：邮箱、密码，返回随机会话令牌、账户 ID 与过期时间。
3. 私有请求携带 `Authorization: Bearer <token>`；后端查数据库验证会话，服务器自行确定租户。
4. `GET /api/snapshot` 可在原估值事务内采用公共价格库中已经存在的新收盘价，不联网；有变化才推进账号版本，响应头 `x-data-revision` 表示采用后完整快照的最终版本。
5. 账号修改请求携带 `If-Match: <revision>`，在用户数据库锁内检查。缺失/旧版本通常返回 409，客户端保留输入并要求刷新核对；财务写入会先按本账号持久回执识别已提交的相同请求并返回当前快照。分析预览、模型连接测试、财务回执查询、公司代码解析及公共分红日历刷新不要求账号版本；公共目录保存校验其独立的目录版本。例外由服务端版本策略显式声明，其他 POST 预览入口不能据名称推断为免版本。
6. `GET /api/sync/version` 返回 `{ "revision": "..." }`。前台轮询合并请求、空闲降频、失败指数退避。版本不变不读取全量业务快照；有待确认草稿时不覆盖界面。
7. `POST /api/auth/logout` 撤销当前会话，其他设备保持登录。管理员重置密码撤销账号全部会话。

写入成功后客户端接受响应版本；读取版本接口、GET 汇率设置和 AI 响应不会提前推进表单基准版本。完整快照尚未加载时，不能用这些局部读取确认其他设备的新资料。版本同步只读取已保存的数据，不查询行情或刷新账号汇率；删除操作同样产生版本更新。

离开将卸载的编辑页前，应用会询问是否放弃未保存输入；取消浏览器历史或地址跳转时保留原页、地址和草稿。同页导航不清空草稿；问答页常驻保留输入，切到辅助页面后仍可返回继续。搜索、筛选和排序属于展示状态，不触发草稿放弃提示。

同步状态统一显示在侧栏，移动端顶部提供同一状态入口；点击进入“账号与数据”。

## 边界

数据实时写入服务器，不在设备间上传/覆盖整库快照。离线无法保存，前端保留当前页面输入但没有持久离线队列。财务请求超时或 5xx 时先查询只读回执，未知结果保留原请求核对；不自动创建新修改。服务器能读取业务明文，没有端到端加密。

JSON 导出/导入用于备份与迁移，不是同步协议。导出包含个人档案、账本、每日原始条目、研究与复盘、分析历史、个人观察资料及允许备份的设置；设置仅包含统一汇率表/历史汇率、投资方法论和账号观察规则。模型配置、问答预设、API Key、登录会话及全局公共目录/行情库不进入账号备份。`POST /api/data/import` 默认仅允许空账号，显式加 `?replace=true` 可替换当前登录账号上述可备份数据，不合并，也不影响其他账号；目标账号的登录与不在备份内的配置、密钥保留。两种导入都要求 `If-Match` 版本，校验或写入失败时事务回滚。

页面中勾选“覆盖当前账号已有数据”并选择 JSON 文件后，确认抽屉说明全部替换范围、失败回滚及备份恢复方式；还须勾选“我已导出当前数据”才允许确认覆盖。确认后会先下载 `mario-before-import-时间.json` 备份，再执行覆盖。覆盖请求绑定备份时的账号和数据版本；备份后若有新写入，服务器拒绝覆盖，需核对后重新选择文件。请允许浏览器下载并保管备份；需要回退时，可将该文件再次覆盖导入。登录信息及模型、行情密钥保持在目标账号中。PostgreSQL 完整备份和主密钥必须由管理员单独保管。

## 备份版本

当前同步数据集为 v28，租户数据库 schema 为 15；两者独立版本化，数据集版本描述 JSON 结构，schema 版本控制账号数据库的一次性迁移。数据集包含账号观察规则、买点观察名单、分红依据、逐日历史、未读状态及当前股数网格；旧比例网格仅保留历史参考。v27 及以前缺少账号规则时恢复默认配置；v24–v26 的观察与旧比例网格按[观察升级规则](buy-watch.md#数据升级与验证)在原事务中迁移，v23 及以前备份恢复为空观察名单。观察数据与财务数据一起事务恢复，失败整次回滚。早期备份按各自版本的结构校验后在单一事务内恢复，失败整次回滚：

- 含早期交易结构的 v1–v17 包整次拒绝恢复，不覆盖现有数据；不含交易的财务包按原结构恢复。
- 旧投资目标与组合流水（v1–v18）、组合检查点（v1–v16）、决策与结构化决策复盘（v1–v15）、长期记忆偏好表（v1–v21）只校验结构并跳过，不重建已退役功能；其他有效资料继续恢复，历史问答正文与冻结引用保留。
- v18–v20 恢复时保留已有现金余额，不重放历史现金流。现金核对基准、逐交易现金归属、更正历史、操作回执、异常隔离、公司行动与精确会计源自 v21 起包含在备份中；交易字段与成本算法见 [真实成交与持仓](holding-trades.md)。
- 新版备份需使用新版服务恢复。

投资方法论正文随账号数据备份保存，导入前检查非空及 4000 字符上限，失败不覆盖当前数据。备份未包含方法论时恢复为初始范本；模型密钥与账号登录信息不进入数据备份。旧格式适配仅服务存量备份恢复，停止支持对应版本后才可移除；不得因规范整理直接丢弃备份、财务审计或仍需恢复的数据。
