# 自建服务信任边界

当前部署从本地单用户改为多账号服务器，旧本地端到端快照模型不再适用。部署与恢复见 [自建部署](self-hosting.md)。

- 服务器管理员被信任：业务数据在 PostgreSQL 中为明文；磁盘/备份加密由基础设施提供。TLS 保护网页及客户端连接。
- 密码使用 Argon2；随机会话在数据库保存 SHA-256 哈希，有效期 7 天，可撤销。注册需要管理员邀请码；内置并发与账户登录频率限制，公开服务还应增加入口 IP 限速。
- 用户身份来自已验证会话，schema 名由账户 UUID 生成。请求没有租户选择参数。用户不能直接连接数据库；数据库管理员具有访问所有账号数据的能力。
- 每账户模型密钥使用 ChaCha20-Poly1305 加密并绑定用户与密钥用途；主密钥在部署环境中，不能随数据库备份泄露。JSON 业务导出不含这些密钥。
- 独立 AI Agent 只接受内部令牌，接收冻结且经过用户授权的上下文，不拥有数据库网络或连接信息，不提供业务写入接口。模型提供方会收到完成当前任务所需的授权数据。
- 托管模式禁用服务器本机 Codex 登录；用户可自行配置任意 HTTP/HTTPS 模型地址及端口，不依赖主机白名单。模型请求由 API 或 Agent 所在服务器发出，可访问其网络中的地址；网络出站边界由部署环境管理。地址不允许内嵌凭据、查询参数或片段，不跟随重定向。
- 前端按服务器地址在 `localStorage` 保存会话凭证及过期时间，服务端验证其 7 天有效期和撤销状态；退出清除本机凭证。不同服务器的凭证隔离，不在客户端持久化业务数据库；离线草稿只在当前界面，不声称已在本机持久保存。
- 版本检查与写入串行化由 PostgreSQL 完成，前端提示并不能替代后端冲突校验。
- 所有网页与依赖都属于会话安全边界，需及时升级；部署生成的 Nginx 片段提供 CSP、禁嵌入、禁 MIME 猜测等响应头。

当前不包含邮箱验证、邮件密码恢复、MFA、设备管理 UI、端到端业务加密或持久 AI 任务队列。管理员可通过 CLI 重置密码并撤销账号所有会话。
