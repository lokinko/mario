# 自建服务信任边界

mario 是多账号自建服务，信任边界如下。部署与恢复见 [自建部署](self-hosting.md)。

- 服务器管理员被信任：业务数据在 PostgreSQL 中为明文，磁盘加密由部署环境负责。Mario 整站迁移脚本另提供密码加密的备份包；该包的保护范围见下方密钥说明。TLS 保护网页及客户端连接。
- 密码使用 Argon2；随机会话在数据库保存 SHA-256 哈希，有效期 7 天，可撤销。注册开放，无需邀请码；内置并发与账户登录频率限制，公开服务还应增加入口 IP 限速。
- 可选网站 ChatGPT 身份登录只请求身份 scopes；OAuth 登录事务使用 PKCE/state/nonce、浏览器 HttpOnly Cookie 和数据库原子消费，服务端验证签名与声明。外部身份不按邮箱自动合并；关联必须绑定并重新验证原 Mario 会话。OpenAI 原始令牌与 client secret 不进入浏览器或业务备份；网页仅获得现有 Mario 自有会话。HTTP 日志不包含查询串。接入资格、回调配置及尚未覆盖的上游账户安全通知见 [网站登录](chatgpt-sign-in.md)。
- 用户身份来自已验证会话，schema 名由账户 UUID 生成。请求没有租户选择参数。用户不能直接连接数据库；数据库管理员具有访问所有账号数据的能力。
- 每账户模型密钥使用 ChaCha20-Poly1305 加密并绑定用户与密钥用途；主密钥由部署环境保存。个人 JSON 业务导出不含密钥。单独的数据库副本不包含部署主密钥，但由 [backup-common](../scripts/backup-common.mjs) 生成的整站加密迁移包有意同时封装数据库与主密钥，以便恢复账号模型凭据；持有迁移包及其密码的人拥有相应访问能力，不能把它视为不含密钥的普通数据库备份。具体保护及恢复见[迁移规范](data-migration.md)。
- 独立 AI Agent 只接受内部令牌，接收冻结且经过用户授权的上下文，以及完成供应商调用所需的配置和密钥；不接收账号数据库连接信息，不提供业务读写接口。其进程网络隔离由部署环境负责，代码模块边界不等于网络沙箱。模型提供方会收到完成当前任务所需的授权数据。
- 服务器不使用本机 Codex 或 ChatGPT 登录，两种订阅执行方式只能经用户电脑上的配对桥接调用。官方 OAuth 仅在本机接收 `127.0.0.1` 回调，验证 PKCE/state/nonce/签名身份与授权范围，令牌只存当前系统用户配置目录，受 owner-only 权限和原子写入保护；服务器、网页、备份和日志不接触令牌。操作系统同一用户或本机管理员仍被信任，文件权限不抵御该用户下的恶意程序；用户可在 ChatGPT 设置撤销授权。固定官方推理端点不跟随重定向，也不因限额失败自动切换计费方式。已有的普通 API 方式中，用户可自行配置任意 HTTP/HTTPS 模型地址及端口，不依赖主机白名单。模型请求由 API 或 Agent 所在服务器发出，可访问其网络中的地址；网络出站边界由部署环境管理。地址不允许内嵌凭据、查询参数或片段，不跟随重定向。
- 前端按服务器地址在 `localStorage` 保存会话凭证及过期时间，服务端验证其 7 天有效期和撤销状态；退出清除本机凭证。不同服务器的凭证隔离，用户自定义的服务器地址也只保存在本机且切换后需在新服务器登录，生产 CSP 仅允许同源连接；不在客户端持久化业务数据库；离线草稿只在当前界面，不声称已在本机持久保存。
- 版本检查与写入串行化由 PostgreSQL 完成，前端提示并不能替代后端冲突校验。
- 所有网页与依赖都属于会话安全边界，需及时升级；部署生成的 Nginx 片段提供 CSP、禁嵌入、禁 MIME 猜测等响应头。

当前不包含邮箱验证、邮件密码恢复、MFA、设备管理 UI、端到端业务加密或持久 AI 任务队列。管理员可通过 CLI 重置密码并撤销账号所有会话。

## 实现与验证依据

[accounts](../server/src/accounts.rs) 与 [hosted](../server/src/hosted.rs) 实现会话、租户选择和版本检查，[密钥模块](../server/src/secrets.rs)处理账号及用途绑定；[托管 HTTP 验收](../scripts/test-hosted.mjs)覆盖跨账号隔离、跨实例冲突、密钥导出排除、重置密码和会话撤销。[Agent](../server/src/agent.rs)及[架构检查](../scripts/check-architecture.mjs)约束代码依赖和接口，并不验证宿主机网络隔离；网站 OAuth 与本机凭据的专属测试分别见[网站登录](chatgpt-sign-in.md#实现与验证依据)和[本机桥接](codex-bridge.md#自动化验收)。

[原生恢复门禁](../scripts/test-financial.mjs)通过直接 `pg_dump` / `pg_restore` 验证数据库表恢复；[加密备份验收](../scripts/test-backup.mjs)另测密码、篡改、主密钥恢复、会话撤销和失败回滚，由 `npm run test:backup` 显式执行，当前未接入完整 `npm test`。测试通过不等于完成线上 TLS、Nginx、出站网络或真实 OAuth 验收；历史审计也不代表本次重新执行。
