# 本地原生应用威胁模型

## 保护目标

mario 需要保护三类高价值资产：用户投资与财务数据、模型 API Key、云端账户令牌和同步恢复密钥。其次要保护决策日志、复盘与研究证据的完整性，避免其他本机网页或程序静默读取、修改或触发模型请求。

## 信任边界

```text
Tauri WebView ── Tauri command ── 每次启动配置
      │                              │
      │ Authorization bearer        ├─ 随机回环端口
      ▼                              └─ 256 位随机令牌
Local Axum service ── SQLite / platform secure storage
      │
      ├─ 用户选择的模型服务
      └─ 用户选择的账户与密文存储服务
```

原生外壳、本地服务、SQLite 和平台安全存储位于受信任侧。模型提供商、云同步提供商、研究证据正文和任何模型返回内容均视为外部或不可信输入。

## 已覆盖的威胁

| 威胁 | 当前控制 |
| --- | --- |
| 恶意网页扫描固定本机端口 | 原生客户端使用随机回环端口；CORS 只允许 Tauri 与本地开发来源 |
| 其他本机 HTTP 客户端直接调用接口 | 所有 API 要求每次启动生成的 bearer token |
| 令牌从命令行参数泄露 | 令牌只通过子进程环境和 Tauri 管理状态传递，不写入 argv、SQLite 或日志 |
| 旧 sidecar 残留 | sidecar 监控桌面父进程并随其退出；新实例使用独立端口和令牌 |
| 模型密钥进入数据库或提示词 | 模型密钥只保存在平台安全存储，只进入模型请求 Authorization header |
| 云服务读取投资明文 | 投资快照在本机使用 XChaCha20-Poly1305 加密；恢复密钥按账户保存在平台安全存储且不上云 |
| 多设备覆盖彼此修改 | 云端 revision 原子比较；版本冲突停止上传，拉取替换需要用户确认 |
| 已冻结期间被静默改写 | 组合流水只追加；检查点冻结所用流水 ID 与汇总，服务端拒绝向最近检查点之前回填 |
| 恶意或错误 CSV 破坏归因链 | 2 MB/1000 行上限、严格字段校验、写入前逐行预览、稳定编号去重、冲突整批阻断、预览版本复核与 SQLite 原子事务 |
| 模型或历史内容注入指令 | 固定系统策略把本地上下文、证据、记忆和上游模型产物作为不可信数据；最终结果执行结构与引用白名单校验 |

## 残余风险

- 已经获得当前系统账户或 Android 应用进程控制权的恶意程序，可能读取未加密 SQLite、检查进程内存、模拟用户操作或调用平台安全存储；进程令牌不声称抵御整机失陷。
- Android 端不能执行桌面 sidecar，因此在 Tauri 进程内启动同一 Rust 服务库；仍只监听随机 loopback 端口并要求同等级 Bearer Token。Android WebView 为访问该端口允许 cleartext，但 CSP、CORS、loopback 绑定和令牌共同限制调用边界。
- 当前本地数据库尚未静态加密；磁盘副本、未加密备份与取证场景仍可能暴露投资数据。
- WebView 或前端依赖中的可执行脚本漏洞可能在受信任窗口内调用 Tauri command，因此仍需依赖锁定、CSP、代码审查和发布签名。
- 系统通知能力只有在用户从复盘中心主动开启后才请求；通知内容不包含资产名称，提醒开关和去重状态仅保存在本机且不进入同步包。
- 应用尚未完成 Apple Developer 签名、公证和签名自动更新；当前 DMG 只适合开发测试。
- 外部模型提供商会接收用户在发送前预览中确认的上下文；其后续存储、训练与访问政策不由 mario 控制。
- 云端对象的密文长度、更新时间和版本号属于可见元数据，端到端加密不隐藏这些信息。
- 用户填写的估值日期与折算汇率不是可信行情源；缺失时系统停止组合级计算。用户可主动查询 ECB 参考值，系统冻结来源和观察日，但它仍不是券商成交、银行结算或税务汇率，AI 不得把它描述为已验证成交事实。
- 汇率 Provider 使用固定 HTTPS 主机、固定币种白名单、请求超时和响应体上限；服务端不接受用户自定义上游 URL，避免把该接口变成 SSRF 或任意下载通道。
- 组合流水同样来自用户输入；只追加和日期边界可以保留审计链，但不能证明券商、银行或税务事实完整无误。
- CSV 中的公式、脚本样文本和说明均按普通文本处理，React 默认转义展示且不会交给 shell；系统仍不能证明文件来源真实性。来源与外部交易编号只用于本地审计和加密同步，不发送给模型。

## 发布前验证

1. 无令牌和错误令牌访问任一 `/api` 路径必须返回 `401`，正确令牌返回预期结果。
2. 令牌不得出现在进程参数、日志、SQLite、分析审计或云同步包中。
3. 同时启动两个桌面实例时，它们必须使用不同端口和不同令牌。
4. 桌面父进程退出后，关联 sidecar 必须停止；Android 应用进程退出后，内嵌服务必须停止。
5. 依赖升级后重新执行客户端构建、Rust 测试、Clippy、桌面安装包和 Android APK 构建，以及实际启动检查。
