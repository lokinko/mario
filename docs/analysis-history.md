# 可审计的 AI 分析档案

mario 把成功完成的 AI 分析保存为本地研究档案，不把它们当作聊天流，也不因为时间过去就自动改写。档案用于核对当时问了什么，以及模型实际使用了什么。

## 保存内容

每条分析冻结：

- 用户当时的问题、生成时间和确定性渲染后的最终回答；
- Provider、模型、上下文分组、证据数量、调用耗时和可用的 token usage；
- 工作流版本与调用轨迹（v7 及更早报告还保留研究计划、候选方案和风险审查，只供读取）；
- 通过校验的结构化报告、当时允许引用的证据目录和输出修复记录。

模型 API Key 和会话令牌不进入分析档案。

## 浏览与重新使用

`GET /api/analyses` 返回最近 50 条索引，用于客户端历史列表；`GET /api/analyses/{id}` 按不可变 ID 读取完整记录。单条读取不受“最近 50 条”限制，可读取较早的完整分析。

问答页的“历史对话”只展示问题和时间，打开后与新回答共用完整 report 展示，不显示工作流轨迹或审计面板。后台仍保留完整档案，可通过上述 API 读取。

客户端允许：

- 重开结构化报告及其来源链接；
- 在历史 report 后继续追问，附上一轮问题与结论摘要，并按设置中的预设使用当前资料；
- 选择“新对话”清空当前对话上下文。

历史 report 保留当时的内容。继续追问会重新构建和冻结当前资料指纹，不复用旧载荷。资料范围与联网选项在“设置 → 问答预设”一次配置，提问时自动执行准备与指纹检查。

## 认识论边界

历史分析应被理解为尚未经过实际结果验证的模型记录；当前问答页显示报告和时间，并未为每条历史答案单列“未经结果验证”标签。引用抽屉遇到旧模型回答类来源时会显示该限定。档案记录模型当时说了什么，不证明：

- 当时的事实摘要正确或完整；
- 推断在逻辑上成立；
- 今天的财务状态、持仓和外部环境没有变化；
- 相关行动适合当前用户；
- 未来收益有任何保证。

外部事实需要可核对的原始资料支持，来源链接或模型摘要本身仍可能不完整；历史模型回答不能替代原始资料核验。

## 历史读取与迁移边界

当前 `StoredAnalysisReport` 按字段形状分开读取单次报告和早期结构化报告；v8 既有回答与 v9 同形报告均保留原文，新生成仅接受[当前契约](ai-workflow.md#结构化输出契约)。升级和旧备份导入会清理已退役的记忆偏好、`useMemory` 与专属审计元数据，保留历史问题、回答及引用，不恢复长期记忆或旧工作流执行入口。保留的旧类型只服务历史记录和受支持备份读取；停止支持这些数据后才可移除适配。

历史搜索资料可按[研究证据规则](research-evidence.md#相关性检索与冻结)复用；这只提取合格的原生网页来源，不把模型答案当作新事实。打开历史详情期间，接收新公司问题或开始新对话会使旧详情请求失效，旧响应不能清空新问题或恢复旧对话。

## 实现与验证依据

[research 仓储](../server/src/db/research.rs) 实现最近 50 条索引、按 ID 详情及来源复用，[历史报告契约](../server/src/models/analysis_history.rs) 隔离旧结构。[仓储测试](../server/src/db/tests.rs) 覆盖审计/轨迹保存、早期字段缺省、缺失 ID 和记忆退役迁移；[Advisor 测试](../client/src/features/research/Advisor.test.tsx) 覆盖历史重开、追问、新问题与迟到详情竞争，[ReportSources 测试](../client/src/features/research/ReportSources.test.tsx) 覆盖旧模型来源限定。这些非忽略回归由完整 `npm test` 执行；档案读取通过不能证明报告建议正确或已在部署环境验收。
