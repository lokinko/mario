# 复盘与规则闭环

mario 保留独立复盘记录和个人投资规则，用户可从复盘思考中整理规则。

## 周期系统复盘

复盘记录使用一个自由文本框，只需写下用户想表达的内容、顾虑和思考，不要求复盘周期、纪律评分、下一步或下次复盘日期。历史记录按保存日期展示完整正文；早期结构化记录的文字、周期、评分和下次复盘日期合并为正文显示。投资规则保留在折叠区域，用户可以主动把一段复盘思考作为规则草稿的依据。

保存接口只接收 `{ "content": "完整复盘正文" }`，拒绝结构化表单字段；早期结构化记录通过只读适配展示。

保存时，服务端同时冻结当时的组合市值、应急覆盖、集中度、风险状态、高风险项和有效规则数。以后查看这条记录时，不使用当前状态回填旧数据。

## 个人投资规则

一条可以执行的规则至少包含：

1. 类别：资产配置、风险、研究、仓位、行为或复盘；
2. 规则内容：触发时具体要做或不能做什么；
3. 触发条件：何时必须检查；
4. 依据：它来自什么证据、要避免哪种重复错误。

规则可以直接建立，也可以从一条周期复盘的经验转化。修改和停用都会产生新版本，原版本不被覆盖，因此能够判断“当时遵循的究竟是哪套规则”。停用不是删除：规则不再约束新决策，但仍属于历史证据。

## 与问答的关系

问答的冻结上下文不包含个人规则和复盘记录。用户可以从复盘或参考资料页把一段内容带到问答中作为问题；AI 不修改或启用规则，规则只能由用户明确保存。

## 页面内复盘提示

页面保留到期周期复盘的提示和新建复盘入口。新增纯文本复盘没有默认到期日期，不会因日期为空反复触发周期提示。

提示只负责把用户带回复盘记录，不包含行情、涨跌或交易刺激。

## 当前限制

- 周期快照保存聚合指标，不保存完整持仓副本；
- 规则修订需用户人工整理和确认。
