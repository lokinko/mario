# 2026-10-25 界面设计实施验收

依据 [整体设计](../system_ui_design.md) 调整全部前端页面，采用暖白纸张、墨绿和古铜的账簿风格。服务端 API、数据库结构、财务计算、认证、账号隔离、版本检查和部署流程保持现有路径；无需数据迁移。

## 实施范围

| 范围 | 实际行为 |
| --- | --- |
| 基础样式 | 独立设计变量；统一字号、字体、圆角、语义色、焦点和动效；删除旧变量、重复规则及失效的宽度限制 |
| 数字 | 金额按币种补齐小数，精确十进制原文直接舍入；数量与价格支持千分位和指定精度；盈亏带符号，零值中性；输入保留源精度 |
| 应用壳 | 资产／决策／研究导航；同步集中在侧栏与移动顶栏；删除 `PageStatus` 和旧浮动汇率组件 |
| 我的情况 | 首屏资产总览、金额隐藏、页签小计、横向指标带、原币明细、表头排序、键盘菜单、现金核对日期、空记录添加、使用说明抽屉 |
| 资产趋势 | 与总览共用历史请求，默认展开，区间与游标分页；折线、渐变面积、沿用虚线、悬停及方向键逐日查看；不同基准币种分段 |
| 抽屉与反馈 | 宽窄抽屉、底部持仓操作、草稿和忙碌保护；统一 Callout、Badge、DataStamp、菜单、骨架与空状态；消息位于右下角 |
| 问答 | 按时间分组的历史、推荐问题卡、实际资料预览、服务端阶段映射、未校验标记、报告引用抽屉及依据与局限 |
| 研究与复盘 | 月份分隔和日期时间线，资料状态页签及计数，规则徽标与操作菜单 |
| 方法论与设置 | 方法论工具条、正文编辑、写作提示和覆盖范本确认；设置分区目录、密钥显示切换、本地显示偏好 |
| 账号与登录 | 覆盖导入说明范围、回滚与恢复，要求确认已导出，再下载额外备份并提交；登录采用品牌区与表单布局 |

显示偏好仅存在当前浏览器。默认红涨绿跌，可以切换；隐藏结构化金额及金额输入不修改业务数据，原文、复制与导出仍含真实信息。字号、间距、金额精度和显示偏好的长期约定已同步到 [架构说明](architecture.md#界面与显示约定) 和 [模块边界](module-boundaries.md)。

## 保留边界

- 服务端没有持仓占比及币种分组合计字段，本次不新增前端折算、求和或收益率计算；占比、分组合计及缺少可信输入的百分比按设计推迟。
- 暗色模式属于可选 P3，本次没有实施。
- 不补造历史变化、方法论版本或不存在的元信息。历史只有一天时不画迷你曲线；缺失金额显示 `—`，原币记录保留。
- 原生数值输入显示原始值，避免千分位或排版负号导致浏览器清空输入；分组、补位和排版负号用于输出。服务端无法归属到单个字段的错误继续显示在对应表单的错误提示中。

## 验证

- 完整 `npm test` 通过：架构检查、前端构建／Prettier／Vitest、Rust 格式／严格 Clippy／构建、Rust 测试、HTTP、Web、Codex 桥接与财务发布门禁。
- 完整入口执行时前端 252 项通过；最后的菜单嵌套 Esc 回归加入后，最终前端独立回归为 **38 个文件、253 项全部通过**，并重新通过构建、Prettier 和架构检查。
- Rust 常规套件 **218 项通过、4 项忽略**。忽略项是两个真实 Codex 测试、真实模型证据评估和公共行情接口测试；未调用用户模型额度来替代这些显式测试。
- 财务门禁通过临时 PostgreSQL 的迁移、HTTP、账号隔离、版本冲突、覆盖导入回滚、精确金额、原生备份与恢复，比较 **164 张表**。测试没有读取开发或生产数据库。
- 使用临时 PostgreSQL、独立注册账号和人工样例资产，在 Chromium 检查全部 8 个页面的 **1440×900、1280×800、768×1024、390×844** 视口，共 32 张基础截图；没有文档横向溢出或浏览器运行异常。
- 额外检查金额隐藏、刷新后偏好保留、涨跌色切换、菜单键盘焦点、持仓抽屉、设置目录及实际资料预览。趋势交互截图使用明确的 30 日响应夹具，只验证曲线展示，不作为真实历史财务计算验收。
- 本地截图及视口检查结果保存在 `.runtime/ui-design-2026-10-25/`，未纳入业务数据或 Git。人工检查发现并修复了手机指标四列拥挤、搜索框重复边框和数值输入不接受千分位的问题。
- 静态搜索确认生产样式与功能组件没有旧颜色变量、硬编码色值（变量文件除外）、字号常量、`PageStatus`、页头同步按钮或浮动汇率样式；所有 CSS 变量均有定义。
- 核心正文及语义徽标颜色复核 AA：次要文字在白底 5.21:1、浅底 4.92:1，涨幅砖红在浅底 4.54:1，警告文字在浅底 4.82:1；绿色稍作加深以满足浅底小字对比度。

本次仅提交和推送代码，没有执行部署。开始时已有的未跟踪文件 `server/src/ai/conversation.rs` 不属于此次调整，保留原样且未纳入提交。
