# 文档索引

本索引提供已确认文档的查询入口。当前功能按用户、市场、AI 三域划分，应用装配与公共技术能力作为支撑部分；具体行为、接口、代码映射和验证入口由下列文档维护。

| 查询目的 | 文档 | 职责 |
| --- | --- | --- |
| 理解代码边界 | [架构](architecture.md) | 三域归属、依赖方向、现有代码地图与架构债 |
| 查询用户功能 | [用户域 spec](specs/user.md) | 账号、财务事实、观察、资料、方法论与复盘 |
| 查询市场能力 | [市场域 spec](specs/market.md) | 证券、价格、汇率、分红与采集 |
| 查询 AI 行为 | [AI 域 spec](specs/ai.md) | 授权输入、搜索、分析、历史、记忆与模型执行 |
| 查询工程检查 | [lint](lint.md) | 检查范围、执行入口与覆盖缺口 |
| 查询现有接口 | [API 文档](api.md) | 方法路径、权限、字段、版本与调用约束 |
| 查询协作要求 | [项目规范](../AGENTS.md) | 修改、验证、提交与推送规则 |

## 修改前怎么查

先确定所属域并阅读 spec，再按需要查架构、API 和 lint。实现与测试入口由对应文档提供；涉及多个域时一并核对各域职责与交接契约。

## 发现不一致怎么处理

区分已采纳要求、当前实现和实现差异，核实是文档过时、实现缺陷还是未采纳方案。差异留在所属文档，索引只提供链接；不能把代码现状自动当作产品授权，也不能把已采纳但未实现的行为描述为已经可用。

## 文档如何保留

每份新增文档经讨论确认后纳入索引。规则在所属文档维护，索引不重复摘录业务阈值、接口字段或验证命令。修改行为、契约或验证入口时，同次维护受影响的文档和索引；已取消要求从当前规范移除。

本索引按本轮确认范围重新建立，已删除文档的旧条目不再保留，也不因缺失引用恢复历史内容。文档所列实现或测试入口不代表本次已执行全部验收，提交推送也不代表网站已经部署。
