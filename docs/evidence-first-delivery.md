# 证据优先问答：实施与验收

产品目标：结合个人持仓与整体外部信息，为每条理财建议展示充分、可核对的证据，让用户在使用中理解产品的专业能力和可信边界。

## 已实现并验证的基础

- 工作流 v5 的每条行动必须关联报告内事实，并声明证据局限；缺少关联、越界、重复和缺少局限的输出会被拒绝或进入现有修复流程。
- 问答直接展示逐条建议的依据、来源发布方与日期、局限和确认入口；未关联外部来源时明确展示缺口。
- 冻结本次授权的个人资料、持仓和目标，以及来源摘要和备注；旧报告缺少这些字段时明确标注，不用当前资料替换历史证据。
- 外部信息覆盖区分候选来源与实际引用，避免把提供给模型的所有资料称为已采用证据。
- 模拟接口浏览器检查覆盖问答、确认、证据回答与手机横向溢出；已有前端与服务端回归测试，最新结果见当前测试输出。

## 完整目标尚缺的工作

1. 外部信息获取与汇总：已改用 OpenAI Responses / Anthropic Messages 的原生网页搜索，移除本地世界银行抓取和刷新接口。已验证协议、引用解析、搜索错误和暂停续接；实际账户的搜索覆盖、资料时效和模型质量仍需评估。
2. 语义与个人适用性核验：已增加逐建议模型核对，并严格检查个人原值与外部引文的存在性，缺口会限制建议确认。仍需真实案例验证来源完整性、推理正确性、个人约束适用性与错误检出率；同模型独立调用不能被当作可靠性证明。
3. 真实端到端验收：使用固定持仓、可追溯外部原文与可复现模型响应，验证每条建议的个人关联、外部支持、限制与来源打开；覆盖无来源、过期来源、错误引用、授权变化和历史重开。模拟 UI 响应不构成真实来源或模型能力的证据。
4. 信任效果验证：用代表性问题检查用户能否说清建议为何适合自己、哪些证据支持、何时应停止采用。不能用引用数量、调用次数或模型自评替代能力证明。

上述未完成项仍属于当前目标，不能把已上线的证据卡视为完整交付。
