# 理财问答精简评测审计

使用固定虚构快照、12道题及用户指定的 `gpt-6.1-sol`（Responses 接口）。汇总与实施决定见 [finance_qa.md](../../../finance_qa.md#6-评测记录)，复现方式见 [评测工具说明](../../../server/tests/fixtures/qa_eval/README.md)。没有使用账号或生产数据，模型配置密钥不进入文件。

| [行动1](stage1-v8.json) | 7/12 | 单次生成但沿用旧提示与报告；5题引用校验失败 |

每组 JSON 保留当次请求、冻结模型 payload、上下文指纹、答案、结构化报告、实际调用轨迹、引用原文及失败原因。为控制体积，移除重复的展示分组、阶段状态和旧深度中间文本；源报告完整副本保留在本机 `.runtime/qa-eval/`。记录没有重写旧输出，也没有用最终成功覆盖先前失败。JSON 为紧凑格式，可用编辑器格式化查看。

相邻 `*.manual.csv` 是编码代理依据方案四项标准逐题判读的评分，尚未经过独立人工复核。新增数字若是可复算的算术结果、明确提出的建议目标或幅度，不记作编造；错误解释默认值、遗漏幅度或不恰当地扩大问题范围，会记录在评分说明。最终23/24条建议符合四项标准；缺汇率题的“暂缓目标减持”没有明确数值幅度，未计入可参考建议。未发现资料外编造的事实数字或来源，不代表所有建议都已经获得独立专业验证。

`*.score.json` 为脚本汇总。整套质量指标只有所有题目成功并完成评分才有值；`reviewedSubset` 仅表示已成功且已评阅的子样本，失败、跳过题不在其分母中，必须同时查看执行覆盖率。资源均值同样只统计有完整结果的成功题，不能当作全部请求费用；失败调用没有完整轨迹。当前没有独立人工复核，质量率属于代理评阅观察值。

复算示例（仓库根目录执行）：

```sh
node scripts/qa-eval-score.mjs docs/qa-eval/2026-10-25/final-v8.json \
  docs/qa-eval/2026-10-25/final-v8.manual.csv
```

基线先串行完成前三题，保留检查点后，以 `25ee1bc` 的 v7 源码运行其余9题，按三个互不重叠的题目批次并行；追问使用原首题结果。只有测试入口增加按题目过滤及读取该检查点，生产提示词、默认设置与调用链没有变化。初次中断的未完成调用不计入成功题资源均值，耗时与其他串行阶段不是严格同并发比较。原生搜索资料随时点变化，也不构成外部事实质量的独立证明。

阶段中保留的失败揭示了旧双份金额引用和复杂契约的问题；最终通过事实卡、最小报告及短追问解决。尚未恢复模型证据核对；主动网页搜索和本地研究检索的正确性由独立行为测试覆盖，不把本题集当作增强能力已获得收益证明。
