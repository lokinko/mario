# UI 与跨平台验证 · 2026-09-13

## 本次结果

- 精简“我的情况”、问答、决策、流水、记忆、证据页面的重复说明；保留实际日期、沿用状态、错误和授权信息。每日统计口径收进折叠区。
- 移动端左上角打开左侧抽屉，菜单按钮至少 44px，菜单项至少 48px；支持遮罩关闭、Escape、键盘焦点约束、关闭后焦点归位。切换到桌面宽度自动关闭抽屉并恢复页面操作。
- Windows 使用原生 Credential Manager、MSVC sidecar 和 NSIS 安装器；提供开发命令、构建脚本与 Windows runner 工作流。
- Web 提供独立构建/启动命令、同源页面与 API、访问密钥校验、会话断开；持仓与历史仍由服务端 SQLite 保存。使用方式见 [Windows 与 Web](windows-web.md)。
